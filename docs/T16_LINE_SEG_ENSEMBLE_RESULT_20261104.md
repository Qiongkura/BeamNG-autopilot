# T16 线识别推理侧杠杆：hflip TTA 证伪；双种子 SSL 集成 +4.7%（2026-11-04）

## 设计（预注册口径沿用）

- **固定 4 折**：A 早期 utah / B 后期 utah / C east+west+italy / W west 单独留出；
  留出集与 SSL 复核**完全一致**（`HOLD_A/B/C/W`，逐 run 核验：8 个模型
  训练 runs ∩ 留出 runs = **0**）。
- **模型**：`v28_ssl{A,B,C,W}`（SSL 种子 42，init `ssl_pretrain_fold*.pt`）与
  `v29_ssl2{A,B,C,W}`（SSL 种子 43，init `ssl_pretrain2_fold*.pt`）——同折、
  同训练集、不同种子；两模型均未见过本折留出。
- **指标**：`line IoU(近场)`；宏平均 = A/B/C 三折（W 单独报告）。
- **本轮新增**：`--tta hflip`（镜像概率平均）与 `--tta ens`（双模型概率平均）；
  argmax 在模型分辨率、之后走与 `predict` 完全相同的后处理。

宏平均 **0.4561**，fold A **无跳升**。

## 判读

1. **hflip TTA 证伪**：宏平均 0.4576（−0.0212），3/4 折为负——镜像概率平均
   在本数据上没有补票效应；推理侧这条分支关闭。
2. **双种子 SSL 集成是确认的正迁移**：宏平均 **0.5148 → 0.5392（+0.0244，
   +4.7%）**，相对种子42 为 +0.0605；结构性最弱折 A 从 0.2643 → **0.5048**，
   既超过该折最强成员（0.4288，+0.076），也高于逐折 oracle 宏平均 0.5335
   ——成员互补是真实的，不是"挑到好种子"。
3. **不均匀**：fold B 相对其最强单模型 −0.056（种子42 的 B=0.746 本身极强）；
   C 持平；W 居中。集成代价 = **2× 推理**。
4. **对照归因**：基线对集成没有 fold A 跳升（0.2802）——增益来自 SSL 组合的
   互补性，而不是任何双模型集成的通用效应。
5. **结论**：推理侧首个确认杠杆（相对最好单种子 +4.7%，最弱折近乎翻倍）。
   模型**不晋级**（研究臂）；部署接线（FSD 双模型、时延预算、安全门）需要
   单独预注册，本轮不做。
