# 试车场位姿去重候选协议（提案，未冻结）

## 状态与边界

本文件只定义供讨论与离线测试的**候选**样本选择规则，不替代
[T16 采集预注册](T16_PROVING_CAPTURE_PREREG_20261105.md)，不修改其投影、
覆盖率、漆色和环境冻结门；正式导出当前仍阻断。只有规则、输入、版本、
验收与风险审查完成并在实际评测/训练前冻结后，才能考虑接入。

## 原假设与发现

原假设：同站同格逐帧 RGB 字节哈希去重足以避免重复画面。既有采集的静态
位置可出现不同的图像哈希；它们不能仅凭字节不同就被当成独立空间覆盖。
反之，同位置不同朝向是否应视为不同训练样本是数据设计决定，不能默默
更改原预注册的“内容 hash 去重”含义。原始帧与既有 manifest 保留不改。

## 拟议算法（仅限同一站点、同一条件格）

1. 先逐帧独立核验来源、环境、几何及原有冻结资格门；任何失败或 UNKNOWN
   不加入位姿候选，且不占用后续有效帧的哈希或位姿名额。
2. 对通过上述所有门的候选以**唯一、稳定、预先记录**的 source_id 字典序
   排序。排序键、输入文件/帧哈希、采集 run 身份、规则版本、阈值均需写入
   新版本报告，不可覆盖历史产物。
3. 输入位置取实际读回的有限二维坐标，航向为有限弧度；缺失、非有限或格式
   不正确一律标记 `invalid_pose`、拒绝进入候选集合，不以 0 填补。
4. 与**全部已接受候选**比较；平面距离 `< 0.5 m` 且最短航向差
   `< 0.02 rad` 时判 `pose_repeat`。最短角差为
   `abs(atan2(sin(a-b), cos(a-b)))`，处理 ±π 环绕。阈值边界等于阈值视为
   不重复；任一维达到阈值即可保留，因此**原地转向可被保留**。这个语义
   不是“每个保留样本相隔至少 0.5 m”，应在正式冻结前确认是否符合实验目的。
5. 若有多个匹配，记录顺序上第一个匹配的 source_id、距离和角差；不合格帧
   不进入已接受集合。输出全部接受、拒绝及其原因；随后若仍需限额抽样，
   必须独立记录候选数、抽样方法和未选原因。

位姿相近关系不具传递性：A 接近 B、B 接近 C 不代表 A 接近 C。因而排序是
协议的一部分；该规则只保证每一新接受帧不与**先前接受帧**重复，不保证
每个原始帧只属于唯一簇，也不证明跨站/跨格/跨 run 不泄漏。训练/留出隔离
仍须单独进行家族、内容摘要与空间审计。

## 必需验证和不通过行为

- 确定性正反例：静止不同 RGB、A→B→A 回环、±π、阈值内/等于/外、原地
  转向、无效数值、重复 source_id；重复匹配与测量值可复算。
- 集成正反例：真实导出循环中，先失败后相同 RGB 的有效帧不得被失败帧抢占；
  所有拒绝和抽样未选有来源，不能截断。旧输出目录存在时拒绝覆盖；写入故障
  不能污染已有证据。
- 现场验收：每个 run 的环境读回、传感器同源/时效、实际位置与航向容差、
  可证明进程所有权和清理状态均要合格；缺失记 UNKNOWN 或 INCOMPLETE。
- 只有离线与 Tech 证据完整、协议预先冻结、无控制权冲突时，才讨论解除
  导出阻断。任何一步不满足均保留隔离，禁止训练或修改部署默认。
