# T16 seed 45 弱召回归因与预注册（模型方差项，2026-10-05）

- 状态：**归因已完成；预注册为"不可由现有杠杆修复"，需在 R2 判定里按分布报告**。
- 背景：v8+1 px 膨胀下，dev 召回门 4/6 seed 过，唯一未过的是 **seed 45（0.6105）**；
  v8+2 px 下也只有它不过（0.6744，差 0.026）。它是当前 R2 唯一剩下的技术性未过项。

## 1. 归因（四条实测，逐一排除）

| 假设 | 实测 | 结论 |
|---|---|---|
| 训练不稳定（NaN/早停/欠训） | seed 45 末 train_loss **1.6656**（6 seed 里第 2 好，−0.72 sd）、`stopped_by=step_budget`、480/480 步 | **排除** |
| 训练侧信号能提前发现弱 seed | 末 val_line_iou：45 = 0.211（均值 0.234，−0.34 sd）；**跨 seed 与 dev 召回不相关**（最好 val 的 47 是 dev 次差，最差 val 的 44 反而中上） | **排除**（val 不是 dev 的代理） |
| checkpoint 选择能救（best.pt 优于 last.pt） | v8+1 px、6 seed：42/45/47 两者**逐项相同**；43/44 best 精度升但召回降（IoU 更差）；**46 best 崩到 R=0.4599/IoU=0.3785** | **排除**（且反证现用 last.pt 是对的） |
| 数据剂量还能加 | 线剂量实测：16 帧（+0.0214）→ 32 帧（−0.1464）→ 56 帧（−0.1691）**崩溃**；负例峰值 6×，8.5× 转差 | **排除**（两条通道都到最优） |

→ **结论：seed 45 的弱召回是本臂在现有数据/结构下的不可约 per-seed 方差**
（跨 seed dev 召回 sd ≈0.06；45 约在均值下 1.5 sd），不是 bug、不是可选的 checkpoint、
也不是剂量问题。

## 2. 预注册（本项的可执行路径，二选一，都需先定后跑）

### 路径 A：结构/损失侧单因子（较大改动，另立预注册）
- 目标：把整个 seed 分布的上移（而不是挑 seed）。候选（择一，不许同时改）：
  ① 线头的损失加权/难例加权（针对"暗漆/低对比"像素）；
  ② 时序/连续性输入（相邻帧作为额外通道，让阴影里的线段能靠"同一条线的延续"补上）。
- **安全前置**：②必须先证明**不会在无信号处幻觉**（暗漆无对比度已实测：局部对比
  中位 ≈0 → 若结构让它"猜"，等于在阴影里造线）。验证方式：在**结构负例/无线场景**
  上量假线率不得上升（现成 48 帧负例集）。
- 测量：固定 init/480 步/确定性/种子 42–47 配对；主指标 dev 召回（逐 seed）+ 精度 +
  负例假线率；门不放宽。

### 路径 B：接受 per-seed 方差，按分布报告（不改模型）
- R2 判定按**逐 seed 报 + 分布报**：`n_pass/n_fail` 如实列出（当前 v8+1px：召回 4/6；
  v8+2px：5/6），并把"唯一未过是弱尾 seed"作为**模型质量残差**记录，而不是口径问题；
- 若计划层接受"逐 seed 判定 = 报告分布 + 未过 seed 需归因"（而不是"全 seed 必须过"），
  则 R2 在 v8+1/2px 下可判为**条件通过**（唯一未过项已归因为不可约方差，且已给出
  结构侧路径 A 作为后续）。

## 3. 与 v8 裁决的关系

- 路径 A 与 v8 裁决**无关**（两者可并行；A 只在 v8 口径下测量才有意义，因为 v7 下
  recall 的主因是笔画宽度而非模型）；
- 路径 B 需要计划层明确 R2 的**判定语义**（"全 seed 必须过"还是"分布 + 归因"）——
  这是与 v8 定义并列的第二个裁决点，建议一并定。

## 4. 路径 A 变体①实测：**否决**（无收益 + 安全前置不通过）

**因子**：`--line-tversky-beta 0.7 → 0.8`（更强的漏检惩罚；训练器已有旋钮，
不需要改代码）。数据/init/步数/种子全部与 base6x 相同（同一条记录命令，
仅加该参数）；运行 `t16_beta08_20261005`（6 seed × 480 步）。

### 4.1 目标指标：没有收益（v8+1px，去重 9 场景）

| seed | base6x 召回 | β=0.8 召回 | base6x IoU | β=0.8 IoU |
|---|---|---|---|---|
| 42 | 0.7789 | 0.7592 | 0.6200 | 0.6049 |
| 43 | 0.7787 | 0.6999 | 0.6267 | 0.5798 |
| 44 | 0.7567 | 0.7669 | 0.5955 | **0.6350** |
| 45（弱 seed） | 0.6105 | **0.6071** | 0.5101 | 0.5124 |
| 46 | 0.7404 | 0.7208 | 0.6206 | 0.5643 |
| 47 | 0.6948 | 0.6888 | 0.5956 | 0.5929 |
| 均值 | 0.7267 | **0.7071** | 0.5948 | 0.5816 |

→ 均值召回与 IoU 都**略降**；唯一明显改善的是 seed 44（IoU 0.5955→0.6350）；
**弱 seed 45 完全没动**（0.6105→0.6071）→ 召回门过门数仍是 4/6。

### 4.2 安全前置（预注册的"负例假线率不得上升"）：**不通过**

| 负例集合 | base6x（seed42） | β=0.8（seed42） |
|---|---|---|
| offroad 假线像素 | 757 | **1 391（+84%）** |
| `a0` 结构负例假线帧率 | 0.4375 | **0.6875** |
| `a1` 结构负例假线帧率 | 0.25 | 0.1875 |
| `ring_123638`（**无线场景**） | 0.24 | **0.92（几乎每帧都报线）** |
| `ring_123950`（无线场景） | 0.0 | 0.08 |
| seed47 全部 | ≤0.0625 | 全 0 |

→ 更强的 FN 惩罚把模型推向"宁可多报"：**在无线场景上从 24% 的帧报假线涨到 92%**。

### 4.3 判定

**路径 A 变体① 否决**：目标指标无收益（弱 seed 不动、均值略降）+ 安全前置
明确不通过（无线场景假线帧率 0.24→0.92）。这正是"负例假线率不得上升"这条
前置被预注册的原因——它抓住了一个真实的回归。

### 4.4 剩余可选（未执行，需另立预注册）

- 变体②：**时序/连续性输入**（相邻帧作为额外通道）——目标不是"提高召回意愿"
  而是"用同一条线的延续性补阴影段"；安全前置同样是负例假线率不得上升，
  且必须额外证明**不靠猜**（暗漆局部对比中位 ≈0，任何"愿意猜"的机制都会
  在无线场景里造线——变体①的教训）。
- 变体③：改**训练数据的光照分布**（新采"有影路段"线数据）——已被 §1.4 的
  对比度实测否决（信息不在图像里），不做。
