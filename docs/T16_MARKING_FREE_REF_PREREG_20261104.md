# T16 无标线路段参考重建 · 预注册（2026-11-04）

## 1. 背景

A/B（`T16_INPUT_DOMAIN_RESULT_20261104.md` 追加节）证明：east a0s0 / west a3s0
上 `known_line` 与 `known_no_line` 在 GT 两侧的 paint_ratio **都是 1.0**——
画面里的漆来自地图自带标线，合成贴花在 live 帧中不可区分。因此 live 右线
指标仍不可归因，必须先换到"贴花是唯一漆源"的参考。

## 2. 目标与筛选流程

**目标**：找到一个 live 帧中"地图本身无标线"的路段；在该路段画合成贴花后，
GT 位置出现**新增**漆色（A/B 差分可证），从而建立可信的 live 右线参考。

**筛选（先写死，不按结果调）**：
1. 候选站点：east a1s0 / east a2s0 / utah a3s0（不同地图/锚点，均已知直线段）。
2. 对每个站点以 `known_no_line` 构建（不画任何生成线），采集 20 tick、
   保存帧（`--save-frames`）。
3. 对保存帧计算 GT 左右线（right_lane, 余量 0.6）投影点邻域的
   paint_ratio（与渲染门同判据）。
4. **无标线判据**：左右两侧 paint_ratio 的帧均值都 **<0.2** → 该站点合格。

**验证（合格站点上）**：
5. 以 `known_line` 在同一站点采集；GT 两侧 paint_ratio 需 **≥0.8**；
6. A/B 差分：`known_line` 与 `known_no_line` 同站点帧的像素差在 GT 条带内
   显著高于背景（均值差 ≥8 灰阶，条带内逐点），证明贴花确实新增了漆。

**右线指标（验证通过后）**：
7. 用 `m5_marking_replay`（含渲染门）逐帧分类 H-M0..M3/ok，报告 ok 率与
   右线候选命中；此时指标才可归因于感知。

## 3. 判据（冻结）

- **S1**：至少 1 个候选站点的无标线判据（步骤 4）通过。
- **V1**：该站点 `known_line` 的 GT 两侧 paint_ratio ≥0.8。
- **V2**：A/B 差分条带内均值差 ≥8 灰阶。
- **M1**：验证通过后，回放 ok 率与右线命中率如实报告（无预设阈值——本次是
  "首次可信 live 右线基线"）。
- 若 **无站点通过 S1**：记录"现有四图锚点均带地图标线，live 贴花指标不可
  建立"，需新地图/程序化无标线路段，属外部资源阻塞。

## 4. 纪束与交付

- 全部只读采集/离线分析；不训练、不改默认门、不新增标注、不消费最终集；
- 交付：本预注册、筛选脚本与结果、验证帧/差分证据、右线基线（若达标）、
