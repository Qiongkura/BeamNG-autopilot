## 三、立即待办（下个会话第一件事）

### 1. placement 双线 straddle 修复（代码写了一半，精确方案如下）
**现象**：536×403 下落位失败。诊断（离线复现）：出生点两条线都被识别——中线 lat **-0.3**（车在线左侧 0.3m）、左边缘线 lat **+3.3**。`painted_line_lane_center` 的 straddle 门控（has_left AND has_right → None）拒绝了它。

**精确修复方案**（`beamng_autopilot/vision/lanes.py`，painted_line_lane_center 的 straddle 分支）：
- 出生点恒在路网节点=道路中心 → **最近的线簇 = 中线**（0.3m vs 3.3m）
- 两簇间距 ~3.6m = 双车道道路 → 两簇都按「内侧」处理：目标 = **min_lat 簇 + lane_half_m**（即 shift = lane_half_m − min_lat = +1.8，车左移 1.8m = 中线右侧 1.5m = 本车道中心）
- 守卫：仅当 (max_lat − min_lat) 在 [2.5, 5.0]（双车道宽度）且 ego 在两簇之间时启用；单侧多簇/单簇走现有逻辑
- 改完用探针验证：`painted_line_lane_center` 对出生帧应返回非 None
