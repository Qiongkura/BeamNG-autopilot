## 1. 事实（已实测，不是推测）

1. dev 召回薄弱场景的主因是**暗漆**：标签线像素的 30.67% 是无彩暗像素
   （亮度中位 158–180、色度 1–2），低于白漆门 185；像漆组 189–222。
2. **外观上加档救不回来**（候选 F 否决）：暗档自身 98.5% 不是线；并入白漆门后
   IoU ≤0.471 < 白漆门单独 0.530（精度 0.811→0.43–0.56）。
3. 因此暗漆只能靠**模型能力**（训练数据）或**非外观线索**（形状/上下文/时序）解。

## 2. 因子定义（本草案建议：数据侧，模型能力）

**因子**：在训练集里加入"阴影下/低照度漆线"的**新采**受控场景（漆线材质不变、
只改光照/阴影），剂量按纪律 `DOSE_SAFE_FRAC = 0.15`（线数据安全区实测 ≤0.15，
>0.25 崩），并在**独立**采集批次里生成（不得与评价帧同源）。

- 生成方式（候选，二选一，先做影响分析再定）：
  a) `m5_controlled_scenes.py` 已知_line 场景 + 场景里已有的树影/建筑影
     （italy 有天然阴影路段）→ 用站点规划挑"有影"的路段（只读标签与真值线位置，
     模型无关）；
  b) 采集（`collect`）沿"影多"路线（同 R3 的做法：先只读筛选、再采集）。
- **不选**：改外观判据阈值（F 已否决）、把评价帧回流（纪律禁止）。

- 主指标：**弱场景召回**（`pkg_wide`/`135218` 等 5 个场景）+ dev 池化召回；
  同时报精度（防"召回涨、精度崩"——F 的教训）与 off-road 假线。
- 固定 init / 480 步 / `--deterministic` / 种子 42–47 配对；per-run 划分 +
  因子曝光记录（防静默 no-op）；门不放宽。
- 判定：dev 召回门（≥0.70 逐 seed）在**至少 5/6 seed** 通过、且精度与 off-road
  不劣化 → 该因子成立；否则如实记录（与线/负例剂量曲线同规格）。
