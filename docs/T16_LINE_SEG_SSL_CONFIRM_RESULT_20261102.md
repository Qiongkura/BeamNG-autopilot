# T16 SSL 重复种子复核：效应复现（+0.031 / +0.037，平均 +7.5%）（2026-11-02）

## 设计（配对）

同一 71 族/214 帧池、同一固定 4 折划分；两个随机种子（42/43）各跑
基线（无 SSL）与 SSL（编码器无标签预训练 20ep + 同配置微调 40ep，
SSL 种子对应 0/7）。SSL 只用各折**训练帧**（绝不碰留出帧）。

## 结果

| 种子 | 基线宏平均 | SSL 宏平均 | SSL 效应 |
| --- | --- | --- | --- |
| 42 | 0.4478 | 0.4787 | **+0.031** |
| 43 | 0.4776 | 0.5148 | **+0.037** |
| 平均 | — | — | **+0.034（+7.5%）** |

逐折 SSL 效应（种子42/43）：A +0.031/+0.048、B +0.064/+0.086、
C −0.002/−0.022、W +0.027/+0.005。

## 判读

1. **SSL 效应复现**：两个种子的配对提升均为正且量级一致（+0.031/+0.037），
   **训练侧首个可复现正迁移**成立。utah 折收益最大（A/B），C 折微负
   （−0.002/−0.022，east+west+italy 组合折对 SSL 不敏感）。
2. 基线本身有种子方差（0.4478 vs 0.4776，+0.030）——配对设计是唯一能
   分离 SSL 效应的方法；单种子单跑不足采信。
3. 结论：SSL 预训练是有效杠杆（+7.5%，2/2 种子）；**模型不晋级**（研究臂）。
   SSL 空间（轮数/加噪/容量/无标签帧扩量）未扫，仍有提升潜力。
