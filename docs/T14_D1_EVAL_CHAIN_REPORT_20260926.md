## 3. 计数契约（v5 冻结）

`P_frames`（真值明确含漆线像素的帧，**逐帧判断**）/ `C`（P 帧内候选，覆盖率分母）/
`C_outside_P`（无真值帧的候选，只上报）/ `R`（自身所在侧有可用参考）/
`M`（匹配，M⊆R）/ `L`（可判角色，L⊆M）/ `A`（角色一致，A⊆L）。
比率：覆盖率 R/C、身份率 M/R、角色 A/L；分母 0 → null + 原因。
聚合：**整数求和（micro）为主口径**；macro 只展示且必须注明"每场景一个单位"。
