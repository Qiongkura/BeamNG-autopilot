# T16 域差异对照（重采样灵敏度）· 预注册（2026-11-04）

## 1. 背景

掩码侧诊断（`T16_MASK_SIDE_DIAG_RESULT_20261104.md`）否定 HA：池帧上
raw 黄线召回 east 0.942 / west 0.927，post 0.727/0.889——模型能检出黄线，
live 右线候选召回 ≈0 发生在掩码之后。下一步先排除一个最便宜的混淆：
**输入重采样**。

`Segmenter._infer_logits` 固定把输入 resize 到 536×403（训练域 =
144×192 帧经 INTER_AREA 上采样）。live 相机直接给 536×403 原生帧，
锐度/抗锯齿与池域不同。本对照不模拟真实 live 细节（无法从池帧合成），
只回答"重采样方式本身是否改变召回"。

## 2. 问题与条件

同一批池帧、同一模型 pin（`seg_model_v28_sslA`），四种输入：

| 条件 | 输入构造 | 说明 |
| --- | --- | --- |
| **N**（native） | 原始 144×192 直接送入 | 训练域（内部 INTER_AREA→536） |
| **C**（cubic） | 144→536×403 INTER_CUBIC 预上采样后送入 | 更锐利的重采样 |
| **L**（lanczos） | 144→536×403 INTER_LANCZOS4 预上采样 | 最锐利 |
| **R**（roundtrip） | 144→536 INTER_CUBIC→144 INTER_AREA 再送入 | 锐化后再降采样，测试信息损失 |

GT：`label==2` 按漆色拆 yellow/white（阈值同掩码侧诊断）；预测掩码若在
536×403，则 GT 最近邻上采样到同分辨率后比较（不引入插值把 GT 变宽）。

## 3. 指标

- raw/post 黄线召回、白线召回；
- `drop_frac = 1 − post/raw`（黄线）；
- line 像素数；
- 跨条件差值（相对 N）：Δraw、Δpost（百分点）。

## 4. 判据（跑前冻结）

- **D1**：若 C/L/R 的 post 黄线召回相对 N 的变化都在 **±5pp** 内 →
  重采样不是解释，排除域差异（重采样）假设，转 mask→marking 回放。
- **D2**：若任一条件 post 召回下降 **≥20pp** → 模型对输入锐度敏感，
  属预处理/域问题；记录并进入"输入域归一"课题（需新预注册）。
- **D3**：若 R 条件显著低于 N/C/L（≥10pp）→ 信息损失（降采样）本身有害，
  提示 live 帧若被任何环节降采样会损失召回。
- 不取平均掩盖场景差异：east/west 分别报告。
