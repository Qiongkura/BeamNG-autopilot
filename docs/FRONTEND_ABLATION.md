## 3. 读法（按失败类型，不按名次）

1. **学习前级在这批数据上明显领先**（0.567 vs 最好经典臂 0.271），而且它的**假线像素最少**（380）——
   经典臂的假线都是它的 5–8 倍。所以"经典 CV 能不能替代学习前级"在这批数据上答案是否。
2. **后处理对经典臂的作用远大于对学习臂**：`tophat_otsu` 0.058 → 0.169（+11 点）、
   `ycbcr_pct` 0.201 → 0.271（+7 点），而 `model` 几乎不变（0.567 → 0.567）。
   即：经典臂的原始输出更碎，是靠路面约束+形状过滤救回来的；这也解释了它们后处理耗时高一个量级
   （41–42 ms vs 2.5 ms，因为要处理多得多的连通域）。
3. **`abs` 臂是个具体缺陷，不是"弱一点"**：假线 **182618 px**（等于把整帧判成线），后处理砍不掉
   （0.025 → 0.025）。既有的绝对阈值颜色候选在**这批人工标注帧**上基本失效——这正是计划优先序 2 里
   "明确光照失败"的实测例子（该批帧较暗）。
4. **误删真线**：`model` 1882 px vs 经典臂 2523–3681 px——学习前级的漏检更少，但**它仍然漏掉接近
   1900 px 的真线**（n=20 帧），这是"召回受限"而非"过检"（假线只有 380）。
5. **速度**：经典前级本身很便宜（0.6–2.5 ms），贵的是它触发的后处理。

**没有声称**：n=20 帧属开发验证（计划 §1.5-22 的同类数据已用于阈值扫描），**不构成前端选型结论**；
分位阈值来自文献、**未在本项目标定**；只跑了 Tech 主线数据，Steam 回退路径未动。

## 4. 数据可用性（先查后做）

- 第一版误选了 `logs/m5_seg/run_20260815_010127`：该run **每帧只有约 20 个真线像素**，
  IoU 被假线完全支配（model 臂 0.0046）——**该数据集不能支撑前级结论**，已在扫描 111 个标注目录后
  换成人工标注批（line 占 2.5%）。这条"先查数据再下结论"的教训与 T10 一致。
- 自动标注批（`run_tech_ann_*_y`，320 帧，line 占 10.4%）**明确不作为标线监督**：其 line 类含注入/自动
  palette 成分，按计划"注入 band/annotation 真值不得作真实驾驶证据"的同精神排除。
