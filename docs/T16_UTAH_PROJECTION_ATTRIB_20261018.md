# T16 Utah 投影残差定因记录：a4s0 步进漂移与 a3s0 14px（2026-10-18）

## 范围与约束

- 纯离线定因：仅用已采集帧 `logs/m5_seg/collect_e5line_utah1_20261018/frames/known_line_a{3,4}s0_*.npz`（rgb/annotation/label/depth/camera）与已落盘的 `line_projection_calibration.json`、`scene_known_line_a{3,4}s0.json`、`export_report.json`。
- 不启动引擎、不新采集、不新增人工标注、不改任何冻结门、不消费最终集、不晋级模型；诊断分析代码不落盘、不入池。
- 冻结导出门维持原值：coverage ≥0.8、projection max_after_median_px ≤1.0 且 max_after_px ≤2.0、paint_agreement ≥0.9、truth_provenance=engine_verified。
- 承接 `T16_UTAH_A0S0_OCCLUSION_ATTRIB_20261018.md`（a0s0 阴影定因）之后的两项投影定因：a4s0 步进漂移（原地 vs 步进）与 a3s0 14px 错位。

## 数据与方法

- **站坐标分解**：以 `scene.mid/dir` 建立 (along-station, side) 路面坐标，把 label==2 像素与真值点反投影入该系，区分我方贴花带（side ±1.8±0.25）、地图自有车道漆（side ±2.1~2.2）与中带（side −0.5..+0.25）。
- **逐实例残差复算**：与门同定义（真值点投影→最近 label==2 像素距离；非有限/像外投影剔除；mask >1500px 时门侧等距子采样 `max_line_px=1500`）。复算一致性：a3s0 三帧与门记录逐帧精确一致（14.205/13.969/14.869）；a4s0 f0（mask 1499<1500）精确一致 1.634，f1/f2（mask 2107/1819>1500）全像素复算 4.120/5.564 对门记录 4.555/6.61 略低，差异恰为门的 1500 像素子采样（`line_distance_stats` docstring 载明"最近邻距离略微高估"）。
- **渲染覆盖直方图**：我方贴花带像素按 2m 站距分箱，逐帧对照世界固定性。
- **埋深检查**：贴花带侧（side ±1.55~2.05）处深度反投影表面 z 与链 z 之差，区分"埋入路面"与"对象缺失"。
- **条纹色全图扫描**：r≥175 & g≥135 & r−b≥75（排除红土 (170,134,107)：r−b=63），逐像素反投影到站/侧坐标，排查贴花位移/微弱透过。
- 位姿链复核：三帧相机位置逐步位移 2.00m 沿向、横向 ≤21mm、yaw ≤1°（非传送、非漂移）。

## 一、a4s0 投影残差步进漂移（原地 vs 步进）

### 现象

| 来源 | pooled 残差 |
| --- | --- |
| probe 原地单帧（起点视角） | 0.892px |
| 批次 f0（起点） | 1.634px |
| 批次 f1（+2m 步进） | 4.555px |
| 批次 f2（+4m 步进） | 6.61px |

### 逐实例分解（门同定义复算，mean / median，n=像内真值点）

| 帧 | left | right |
| --- | --- | --- |
| f0 | 0.990 / 0.826（n=30） | 2.278 / 1.148（n=30） |
| f1 | 1.191 / 0.846（n=28） | 7.049 / 8.697（n=28） |
| f2 | 1.161 / 0.832（n=27） | 10.135 / 12.879（n=26） |

步进漂移全部来自 right 实例（mean ×4.5），left 全程 ~1px 稳定自证。

### 已排除假设

1. **位姿链/传送漂移**：逐步位移 2.00m 沿向、横向 ≤21mm、dyaw ≤1°，与"残差随步进单调增大"不构成位姿累积形态。
2. **相机姿态/标定误差**：全局误差会同时推动两个实例；left 逐帧 ~1px 排除。
3. **链-贴花横向位移**：有像素处（stn 4–15）贴花带 side 与链侧差 ≤0.2m，远站在**世界系**贴花无从测位（无像素），不存在"贴花整体横移"证据。
4. **贴花被路面掩埋（z-fighting）**：贴花带侧表面 z − 链 z = +0.09~−0.12m（f2 逐站），表面与链同高或更低，浮贴应当渲染。
5. **距离/mip 截断**：截断站位三帧世界固定（stn≈15），若为视角距离截断应随步进每帧 +2m 平移，实测不平移。
6. **annotation 写入失败 / 阴影（a0s0 型）**：beauty 远右带同为路灰 (151,146,135) 无漆，双 pass 同缺，与 a0s0"annotation 写入而 beauty 无漆"形态相反。

### 定因证据链

- **渲染覆盖直方图**（label==2、side∈±1.55~2.05、2m 箱）：两贴花带的像素全部落在 stn≈4–15，逐帧世界固定（f0 right 4:241/6:81/8:30/10:19/12:9/14:1；f1 4:244/6:155/8:51/10:30/12:8；f2 6:77/8:141/10:39/12:27/14:2；left 同形态）。我方贴花**渲染范围**只有约 11m，而真值链声明 4→33（30m）。
- **远站真值点的服务源随视角切换**（最近像素反投影世界站/侧）：
  - f0：right stn 18–32 由**地图自有右车道漆**（sv≈38、side −2.1）服务，0.3–6.9px；
  - f1：right stn 20–32 由**中带**（sv≈11、side −0.2~0.0）服务，8.9–12.2px；
  - f2：right stn 16–24 由本带端像素（sv≈14）6.4–16.7px，stn 26–32 由中带/左带远端（sv≈24/34）15.7–17.9px。
- 同一批世界真值点在三帧里由**不同线的像素**作最近邻，服务几何随视角改变、距离逐帧增大——这就是"步进漂移"的全部来源。
- probe 原地 0.892px 与 f0 的 1.634px 同处"地图车道漆续线尚能服务远站"的视角区间；步进后服务源切换，残差即升。

### 结论

a4s0 的投影残差步进漂移**不是位姿或链几何漂移**：我方两贴花的渲染范围世界固定止于 stn≈15（链 4→33），stn 16–33 的真值点没有本实例像素可证，其距离是文档化的"缺线证据→量到另一条线"假残差；服务像素随步进由地图车道漆续线切换到中带/邻带，逐帧增大。left 全程 ~1px 自证。贴花对象级渲染范围为何止于 stn≈15 见"未定因"。

## 二、a3s0 14px 系统错位

### 现象

门记录 pooled after 14.348 / median 14.205，逐帧 [14.205, 13.969, 14.869]（复算精确一致）；coverage left 0.9778 / right 0.0。

### 逐实例分解（门同定义复算，mean / median）

| 帧 | left | right |
| --- | --- | --- |
| f0 | 1.954 / 0.943 | 26.455 / 18.297 |
| f1 | 0.738 / 0.450 | 27.673 / 19.580 |
| f2 | 0.518 / 0.467 | 29.771 / 21.694 |

- right 全部真值点的最近像素**都是左带**（服务像素 sv≈20–27、side +1.4~+2.1），距离 12–96px 随站衰减（远站接近左带远端）；右带没有任何像素可作最近邻。
- 右带 annotation 像素逐帧 0/0/0（左 91/378/873）：右贴花在 annotation pass 零写入。
- pooled 14px ≈（left ~1px + right ~27px）/2，即文档化假残差模式的直接形态——**不是系统性的相机/链偏移**。

### paint 84/84 的真伪

- 右链投影处 beauty 为红土 (170,134,107)；导出门 `paint_like` 松黄色判据（RG_MIN=120、B_MAX=140、RB_MIN=60、|r−g|≤45）在 r−b=63≥60 处匹配 → **84/84 是判据在红土上的假阳性**，不是贴花证据。
- 条纹色扫描（r≥175 & g≥135 & r−b≥75）右带仅 2–16 像素 (175–186,137–148,99–107)，介于土色与左贴花 (193,158,106) 之间且 lab=0，无论归属（亮土块 vs 贴花微弱透过）均不构成 annotation 线证据。

### 已排除假设

1. **右贴花被路面/肩土掩埋**：右带表面 z − 链 z = −0.12~−0.03m（表面低于链），浮贴应当渲染。
2. **左链或相机系统性错位**：left 残差 0.5–2px 正常，逐帧自证。
3. **投影标定越界伪影**：a3s0 三帧 yaw 均顶 +1.5° 上界（记录在案），但 left 在同一标定下 ~1px；14px 不由标定产生。

### 结论

a3s0 的 14px **不是"系统偏移"**：右贴花对象级缺失（双 pass 零渲染/零写入），右链 30 个真值点全程量到左带像素（12–96px）；pooled 14px 是假残差。projection 14.35 与 coverage 0.0 两个门失败**同一根因**（右贴花缺失），coverage 门的隔离行为正确。

## 共同结论与门语义

- 两案同族：右实例线证据**范围级/对象级缺失**（a4s0 渲染范围止于 stn≈15、a3s0 全缺），残差数字度量的是"缺证据时量到别的线"，不是相机、位姿或链几何误差。
- **不改门**：projection / coverage / paint 门维持冻结值；a3s0/a4s0 维持隔离；本批 0 帧入池；模型未晋级；最终集未消费。
- paint 判据的照度/材质敏感性（a0s0 阴影下绝对亮度失败、a3s0 红土上松黄色假阳性）为已记录门语义，不作为放宽理由。

## 未定因

- **贴花对象级缺失的生成侧根因未定**。候选：（1）生成器 spline/对象 extent 截断（a4s0 两带同止于 stn≈15、左右对称，指向共同的范围限制）；（2）a3s0 右对象创建失败或整体落在路幅外（该侧 beauty 为土肩）；（3）引擎侧贴花网格生成/投影差异。区分需引擎侧诊断变量分离（诊断输出不进训练池），本次纯离线不做。
- a3s0 右带 2–16 个条纹色候选像素（lab=0）归属未定（亮土块 vs 贴花微弱透过）；不影响结论（annotation 线证据为零）。
