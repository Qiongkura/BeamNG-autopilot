## 2. 结论

第二独立重复**没有复现第一轮的稳定正向效果**（第一轮 E−H=+0.1003、5/5 正向）。
这意味着第一轮结果不能写成稳定的 engine-provenance 优势；更保守的解释是：
小池、单一初始化、60 步预算下，种子/训练崩坏变异主导了跨池差值。崩坏诊断对本轮
很关键：E 臂两个种子 collapse，但即便排除后也不能把它改写成确认性收益。

因此：

* 不晋级模型、不改任何硬门；
* 不把“engine 池优于 human 池”写成稳定主张；论文应报告第一轮正向结果与第二轮
  不复现结果，合并为**池族效应未确定、强烈依赖 seed/小池配方**；
* 下一步应优先扩大独立池族/样本量或扫描步预算，而不是单独追加同配方训练轮数；
  训练回路的 collapse diagnostic 已经证明应作为拒绝/needs-evidence 辅助证据保留。
