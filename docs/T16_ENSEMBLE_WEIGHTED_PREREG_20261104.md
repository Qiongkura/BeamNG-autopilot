## 背景与动机

等权三模型（SSL42+SSL43+基线43）在固定 4 折上宏平均 0.549925（+0.0107），
但 W −0.0103、B −0.0097 触发逐折一致性门 → 不采用。A 折 **+0.0402** 显示
基线种子对最弱折（早期 utah）有真实互补价值；降低基线权重可能保留 A 折
收益、抑制 B/W 退步。

## 臂（等权之外的唯一预设，不扫描其他权重）

| 臂 | 权重（ssl42 / ssl43 / base43） |
| --- | --- |
| W1 | 0.40 / 0.40 / 0.20 |
| W2 | 0.45 / 0.45 / 0.10 |

评测：固定 4 折、`line IoU(近场)`、宏=A/B/C。

## 判据（跑前冻结）

- **R1**：宏平均 ≥ 0.539246 + 0.010；
- **R2**：B/C/W 单折下降 ≤0.005；A 折不得低于 0.5392 水位（即 ≥0.5392）；
- **R3（过拟合声明）**：本实验在同一固定折上选择权重，属于**测试折调参**；
  即使 R1/R2 通过，也只记为**探索性结果，不足以晋级或默认化**。需要一份
  未参与选择的留出数据才能升级为确认结果——当前环境没有，故不晋级。
