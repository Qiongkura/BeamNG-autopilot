## 4. 读法与结论

1. **机制确认、门未过**：观测窗口确实解除了"offer 过期即无 hold 可用"（步骤 0 的
   主导拒绝原因，占 ~75%），复用帧 7→42；车因此多走了 2.7 倍距离、更靠近目标。
   但**爬行依旧是常态**（stall 0.91–0.99），因为**规划器仍只有 12–25% 的 tick 能产出
   可行驶路径**——hold 只能在两次可行驶输出之间维持有界蠕行，改不了输出本身。
2. **安全非劣性按预注册否决**：bC 最大 29→30、R 最大 0→1。差值只有 1 帧、且
   run 间方差极大（off 的 bC 本身在 13–29 之间），但**预注册规则就是"任一项更差即否决"**
   ——不做事后合理化。开关默认关，代码保留（后续若做组合因子可再评估）。
3. **下一条单因子（F-B）的方向因此更明确**：要动的不是"停车/爬行"，而是
   **横向参考质量**——(a) 铺装门撤销了 35% 的已配对车道；(b) 车停在车道左缘
   （`lane_side_off_m` 中位 −2.15 m，限 −0.20），于是任何路径的车体扫掠都越界 →
   规划器拒绝 → 死锁。F-B（撤销后用**观测到的可行驶带**重定中，对**新中心**重跑
   侧向门+铺装门）正是针对这条链，预注册已写好，下一步实施 + 同规则 A/B。
4. **不改变驾驶验收结论**：限定场景 Tech 驾驶仍 **0/4 未过门**，链条停在驾驶层。

## 5. F-B（铺装重定中）：**预注册候选被实测/既有记录否定，未实施**（2026-10-06）

按预注册 §2，F-B = "铺装门撤销后用**观测到的可行驶带**把车道中心重定中"。动手前先做了
两项核对，结论是**这个候选不成立，且第二个候选越界**，因此**不实施、不跑 A/B**：

### 5.1 "用可行驶带中心替代"在本图上是**已记录的负结果**

`bev_corridor_lane_center` / `bev_drivable_center` 正是"观测可行驶带中心"，其 docstring
记录了本图上的实测（`town_1789142315`）：**道路掩码越过车道线外溢 ~1.9 m（路肩）**，
该候选**中位偏右 1.24 m**、**52.7% 的帧偏差 >1.2 m**，实车侧 95% 在道内**没有迁移成功**；
代码里写明"**只作为已记录的负结果保留，除非重新设计**"。用它做重定中＝重复一个已知
错误的横向参考，与"横向参考只能来自感知、且必须落在本车道"的约束冲突。

### 5.2 死锁的几何（12 次 town 运行、512 个"规划车体越界"帧实测）

| 量 | 值 |
|---|---|
| `first_cross_m`（规划扫掠越界发生在前方多远） | 中位 **2.50 m**，p10 2.50、p90 3.00，范围 2.38–4.00 |
| 分布 | **509/512 帧落在 2–4 m**，仅 3 帧 ≥4 m |
| 车速 | 中位 **0.001 m/s**（96% 的帧 speed<0.1 → 静止死锁） |
| `body_cross_current` | **512 帧全为 0**（当前车体**没有**越界，只有规划扫掠越界） |
| `lane_dev_m` / `lane_side_off_m` | 0.86 m / −2.16 m（车停在车道内偏左） |

读法：硬门阈值是 `FSD_PLANNED_CROSS_HARD_M = 4.0 m`（≥4 m 只降速、<4 m 立即停车）。
这里的越界点**恰好卡在 2.4–3.0 m**——即"**充气车体**（半宽 0.9 m + 余量）的左缘刚好压在
车道边界上"，任何带一点横向分量的路径都会在 2.5 m 处触发。也就是说：规则**不是**在
拦截一次严重越界，而是在**惩罚一个边缘化的停车位置**；而车之所以停在那里，是它
先前跟随的横向参考本身偏了（与 `lane_ref_support.n_supported=0`"中心是构造性偏移"
一致，也与 v7/v8 配对研究里"错误配对把车带过车道中心"的归因一致）。

### 5.3 为什么不把 `FSD_PLANNED_CROSS_HARD_M` 从 4.0 调小（死锁的直接"解法"）

把阈值降到 2.0 m 会让 509/512 帧从"立即停车"变成"降速换候选"，即**允许车体扫掠
持续越界 2.5 m 的情况下蠕行**——这是**放宽安全规则**，而且是在"感知参考偏了"的
根因上贴补丁。按项目纪律（安全阈值不单方面改、要改需计划层定夺），**本代理不做**，
只把它作为选项记录（见 §5.4）。

### 5.4 交计划层的选项（附证据，不由本代理执行）

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| ① 修横向参考（**建议**） | 配对/偏移构造质量：让车道中心一开始就落在本车道中心（而非构造性偏移后 0.86 m 偏左） | 属感知侧改动，需走 R2/R3 那套门与预注册；收益直击死锁根因 |
| ② 边缘停车时的"居中回正" | 仅在**静止 + 当前车体不越界 + 感知车道可用**时，允许一段有界回正蠕行（越界点须在 N m 之外） | 实测越界点中位 2.5 m → 需 N≤2.4 m 才有效，等于**局部放宽** 4 m 规则；必须预注册 + 安全非劣性 |
| ③ 降 `FSD_PLANNED_CROSS_HARD_M` | 4.0 → 2.0 m | 直接放宽安全阈值，风险最大，不建议 |

**结论**：F-A 已实测并否决（§1–4）；F-B 的预注册候选**被既有记录与本次实测否定**，
未实施。驾驶层的"停车/爬行"与"铺装重定中"两条候选至此都**没有**产生过门修复，
根因指向**横向参考质量**（感知侧），处置权交计划层。
