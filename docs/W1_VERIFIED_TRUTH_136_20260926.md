## 2. 四条结论

1. **recall 仍是瓶颈，且比 14 帧时更明显**：0.343（生产）/ 0.518（研究候选）；
   两个场景塌得厉害（`233648` 0.034/0.299、`233859` 0.076/0.606）。
   这与 agent 真值下的读数（recall 0.66–0.72）方向完全相反——agent 标注漏标真漆线。
2. **"假线"问题在真值下有了**有证据**的形态**：两个"确认无线"的场景里，
   砾石土路（`123638`）上模型**仍然画出标线像素**（precision 0.0 = 画的都错），
   无标线铺装（`123950`）上两个模型**什么都没画**（全未测）。也就是说假线不是
   普遍现象，而是**特定材质（砾石/土路）触发**——这比之前"路外假线比 0.5+"的
   agent 真值读数精确得多。
3. **场景差异极大**：line_iou 从 0.026 到 0.636（跨 24 倍），任何池化均值都会
   误导；分场景硬门（§10.2/A7）不是可选项。
4. **两个模型的取舍不同**：研究候选 line_iou/recall 明显更好（0.374/0.518 vs
   0.287/0.343），但 road_iou 更差（0.875 vs 0.939）且路口场景路外假线比更高
   （0.261 vs 0.090）。**不能**据此判"哪个更好"——需要逐 seed 配对与任务硬门。

## 3. 对下一步的直接影响

* **E1（Tversky 复验）方向要改**：Tversky 权重 2.0 是压 FP 的，而当前瓶颈是
  **FN**；应测**反向**（beta<1 或提高 line 权重）并在这 136 帧上评价。
* **E3（困难负例）重新有据**：目标锁定"砾石/土路材质触发假线"这一条，
  而不是泛泛的"路外假线"。
* **门槛标定可以开始**：`paint_valid=136`、`pavement_valid=27`、
  `road_type_frames=27`、8 个独立组。但要注意每场景 6–30 帧、单复核人、
  无标注者一致性证据——标定值必须写清这些前提，且不得为让当前候选过门而调低。

## 4. 局限（不要越读）

* 单复核人、一次通过：**没有**标注者一致性证据。
* 两个场景（`123638`/`123950`）**没有标线真值**（人确认无线）：它们的 line 指标
  是"未测"或"有预测但零真值"，**不能**当 0 分或满分读。
* 选帧来自"漆线像素多"的启发式（清晰漆线类）与"确认无线"（另两类），
  不是随机抽样 → 池化 recall 偏乐观，场景内也不代表分布。
* 生产模型与研究候选的训练数据不同，本表**不是**受控对照（对照见 E0/E2）。
