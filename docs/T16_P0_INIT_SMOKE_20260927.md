# T16 P0：初始化对照 1-seed 冒烟（2026-09-27）

方案 §3.3/§3.4 的第一项独立检验："**相同数据/步数下随机初始化与已有模型初始化**"。
这是冒烟（1 seed），**不是效果结论**——效果结论要用冻结的 seeds 42/43/44
（方案 §3.6）。数据、预算、评估集与既有可晋级实验完全一致，唯一差异是 `--init`。

## 1. 设置

| 项 | 值 |
|---|---|
| 数据 | 5 个已验证正例目录（`annotate_pkg_e2_it3` + `annotate_pkg_e1_jv` 四视角），训练 60 帧 / 验证 15 帧 |
| 预算 | `--total-steps 120`（两臂逐字相同），batch 4、lr 1e-3、seed 42、cuda |
| 采样 | `--sampler quota`（全池配额轮换）——两臂 `unique_available=60`、`unique_seen=60`、`exposures_total=480`、`rounds_done=8`，**全池覆盖一致** |
| 差异 | A 臂无 `--init`（随机）；B 臂 `--init t14_e1_promotable_20260927/baseline/seed42/checkpoint_last.pt` |
| 评估 | 8 个 reviewed 开发目录（与既有实验同一 dev 集），口径 `_pixel_eval` + `identity_metrics` |

两臂都 `steps_done=120/120`、`stopped_by=step_budget`（P0 的按 optimizer step
停止与采样器记账在真实训练里生效）。

## 2. 结果（dev 集）

| 指标 | 随机初始化 | 已有模型初始化 | 变化 |
|---|---|---|---|
| line IoU | 0.2611 | **0.3824** | +0.121 |
| line precision | 0.2822 | **0.5389** | **+0.257** |
| line recall | 0.7772 | 0.5684 | −0.209 |
| road IoU | 0.7968 | **0.8604** | +0.064 |
| 路外假线像素 | 241,233 | **31,890** | **−87%** |
| 负例假线像素占比 | 0.02760 | **0.00401** | **−85%** |
| 负例最大连通域 | 105,257 | **25,051** | −76% |
| 候选身份率 | 0.3226 | 0.3450 | +0.022 |
| 左右角色一致率 | 0.7222 | 0.6944 | −0.028 |
| 可测候选覆盖率 | 0.9688 | 0.9781 | +0.009 |

（训练器自己的 val mIoU：0.2719 vs 0.3443，方向一致。）

## 3. 结论与边界

1. **初始化在同等预算下影响很大**：从已有模型初始化显著提高精度（+0.26）、
   大幅减少路外/负例假线（−85%…−87%），代价是召回下降（−0.21）。
   这解释了此前两轮可晋级实验反复出现的"画得更多"模式——那两轮都是**随机
   初始化**，等于在受限配置下测量（方案 §3.3 的原话：先独立检验初始化）。
2. **身份率几乎不动**（0.32 → 0.35），仍远低于 0.60 门。初始化不是身份率的
   解，与方案 §1.3-3 一致（"身份率是唯一硬阻塞"不准确，但身份率也没被这一
   因子解决）。
3. **谱系记录如实**：B 臂 `init_from` / `init_sha16=b3a4dd5a82dd4096` 已落盘，
   父 checkpoint 的 `train_args` 没有 init 字段 → `init_source="random"`、
   `provenance_complete=false`、`parent_history` 为 null、`dataset_id="unversioned"`
   ——**不编造历史**。按方案 §3.5，这种来源只能用于探索，不能作为最终确认的基座。
4. 1 seed 只是冒烟：**不得**把 +0.121 的 line IoU 当作效果结论；下一步按
   冻结 seeds 42/43/44 重跑，并同时记录"固定预算 vs 收敛"的区别（方案 §3.6）。

## 4. 复现命令

```pwsh
# A 臂（随机）
.venv\Scripts\python.exe scripts\m5_train_seg.py `
  --runs logs\experiments\annotate_pkg_e2_it3_20260927\front_fisheye `
         logs\experiments\annotate_pkg_e1_jv_20260927\front_fisheye `
         logs\experiments\annotate_pkg_e1_jv_20260927\front_main `
         logs\experiments\annotate_pkg_e1_jv_20260927\pillar_left `
         logs\experiments\annotate_pkg_e1_jv_20260927\pillar_right `

  --device cuda --save-every-epoch --paint-source human_revision `
  --metrics-run t16_init_smoke_random `
  --out logs\experiments\t16_init_smoke_20260927\random\seed42

# B 臂（已有模型初始化）：同上，追加

#   --out  ...\init_champion\seed42
```
