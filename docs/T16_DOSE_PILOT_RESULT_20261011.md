## 2. 按预注册的解释

1. **方向**：去掉无线帧占多数的池（75→15 帧、同 60 步预算）在两个配对种子上都
   提高了开发集 line IoU（+0.04 量级）。这支持 R3 候选 IoU 下降（0.480→0.370）的
   **稀释假说**：无线帧占 80% 的配比本身在损害线学习，而非"自动数据无用"。
2. **内部一致性**：ArmA 均值 0.4642 与 R3 baseline 0.48025 近似复现（差 0.016，
   在种子变异内）——同配置复现链成立。
3. **臂内种子变异大**（ArmA 两个种子 val mIoU 0.52 vs 0.32、dev IoU 差 0.03），
   与闭环侧的会话级变异结论一致；2 种子只能读方向，不能读幅度置信区间。
4. **precision 形态不同**：ArmB 两种子 precision ≈0.94 且 recall 偏保守；
   ArmA-s43 以 precision 换 recall。哪个形态更好取决于门（recall 0.70 /
   precision 0.40）——本试点不改门，只记录。

## 3. 边界与下一步（不改任何门）

* 单地图池对、2 种子、60 步：**探索性方向证据**，不是配比处方；正式配对
  （5–6 种子、更多线帧池、负例剂量扫描）按方案阶段二第 6 项基于本试点冻结。
* ArmB 15 帧小池的过拟合风险与 val 集组成差异已按预注册如实记录。
* 模型未晋级：交付驾驶模型仍为 `seg_model_hand`（sha 19f54e…），未替换。
