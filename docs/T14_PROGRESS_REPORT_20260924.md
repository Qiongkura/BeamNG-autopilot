## 3. 刚做的（本会话 35 笔提交，按主题分五组）

### A. 停止门与数据身份（4 笔）
1. **手工标注导出丢身份**：48 帧人工修订因"没有地图身份"被拒。修法：导出把
   `map_name/source_id/pos/heading` 写进 npz + `<out>/meta.json` 边车；缺什么就进
   `identity_missing`，审计据此拒绝，**绝不默认地图名**（`204a94e`）。
2. **旧 meta 的地图身份无来源**：28 个采集目录只有 8 个有 `map_name_source`；
   20 个（2508 帧）值无来源，其中 5 个（`ecrev_a/b`、`gm_*`、`holdout_eastcoast`）
   目录名与 `italy` 直接矛盾。审计现在点名这件事（提示不改判）（`4532cb7`）。
3. 复核清单与停止门证据：`02_dataset_audit.json`、`03_needs_review.json`（48 帧逐帧）。

### B. 步骤 3 接线：让"自主循环"真的能跑（6 笔）
4. **`rounds` 三处缺陷**：数据因子只打印 `skipped_factors` 就照训；第 0 轮拿候选自己的
   IoU 当 champion（自我比较）；按位置配对 seed、数量不一致就截断；判定文件名让
   `replay` **重放不到**。修法：因子未生效即拒绝训练；第 0 轮训练**基线臂**并落盘；
   按 seed 键控配对；判定改名 `decision_{cand}.json` 并带 replay 四字段（`b7e687c`）。
5. **审计门内建进 `rounds`**（计划步骤 5："一条命令完成 审计→训练→评估→判定"），
   真实数据实测：不带 `--allow-road-only` 判 `needs_review`、带则进入训练（`0b56e39`）。
6. **提议器只产出训练器能应用的键**（此前发 `group_weights`/`hard_neg_manifest`，
   训练器没实现 → 循环必卡），场景配比族改发可执行的 `add_runs`；无数据时记 blocked
   并停下，不退到"多训几轮"（`60512f1`、`d5d5722`）。真实产物实测：`propose` 产出
   `{'add_runs': [t13_offpavement/front_main]}`，两臂命令只差 `--runs`/`--out`。
7. **轮次判定可重放**：`replay` 现在能找到并逐字重放 `rounds` 的判定（`3e948ca`）。

### C. 反例复核与度量修正（3 笔）
8. **候选复核图**：探针新增整帧复核图（原图+引擎线=蓝+候选命中绿/未命中红）与未匹配
   候选 2× 放大（`e59cfe2`）。
9. **复核结论（限定既有读法）**：引擎 line 类≈"中央线+右边缘"，**沥青上清晰可见的
   白色左边缘线没有引擎标注**（引擎线像素左/右 = 0.021/0.234/0.193，`diverse_wide`
   19/30 帧左侧为零）。因此"离引擎线 ≥2 m ⇒ 假线"不成立（`3fdb57c`）。
10. **按侧判定的匹配率**：分母只含"候选所在侧有 ≥50 引擎像素"的候选——旧 0.221 →
    新 **0.314**；**29.7% 的候选"该侧没有参考"＝未测**（268 个进复核队列，不得当
    hard negative）（`e0644e9`）。

### D. 整通道屏蔽与 road-only 两臂（7 笔）
11. **"忽略某类"被实现成"权重置零"是错的**：权重置零只取消正样本拉力，未标注像素
    仍在 softmax 分母里当负样本 → 教"未标注的可见漆线=背景"。新增
    `masked_cross_entropy`（被屏蔽类移出分母、**梯度恒为 0**）（`6bc1f37`）。
12. **训练器 `--ignore-line-class`**（判据来自标签审计，不是命令行声明）+ 证据落盘
    （`line_ignored_frames`）（`081f047`）；**指标侧同样屏蔽**（`val_line_iou` 记 None）
    （`ddba707`）。
13. **评估补路面类指标**（`road_iou/precision/recall`）（`2ce6483`），`rounds` 解除
    road-only 阻塞：两臂共享屏蔽配方、主指标换 `road_iou`、标线/身份硬门记 UNKNOWN
    （`41ea53d`）。
14. **硬门输入改取实测**（此前 `--hard-p95=45.0` 是命令行阈值被当测量）（`bb589ac`）。
15. **事件流指标名跟着实际配对的那个**（road-only 曾显示不存在的 `line_iou`）（`e234414`）。

### E. 等步数、样本量、看板、采样权重、计时守卫（15 笔）
16. **等步数对照**：先按基线实测步数缩候选 epochs（15 vs 20 步），再升级为**精确等步数**
    （`--max-train-frames` 按 run 配额截帧：候选 40→20 训练帧、两臂 epochs 相同 →
    **15 vs 15 步逐位相等**）（`1498aea`、`a7e9637`、`ac1838d`）。
17. **样本量估算**：成对比较输出 `seeds_needed_for_effect`——那组 +0.039/sd 0.066
    需要 **约 12 个 seed**，不是在 3 个上再加两三个（`2a0368b`、`6d9d915`）。
18. **第二个数据因子：按 run 采样权重** `--run-weights`（超额有放回重复、**每轮样本数
    不变 ⇒ 步数不变**）（`c12ca0a`、`16b03f5`）。
19. **看板 `--run-dir`**：按 `Event.key` 合并 run 级 + 各候选事件流、递归发现本 run 的
    `train_hist.json`、新增"判定与成对比较"节（逐 seed 值/deltas/ci95/verdict/淘汰理由/
    硬门 UNKNOWN 显示"未测"）（`99fdebd`）；实测 30 条曲线 / 8 条事件 / 终态 rejected。
    **更正**：先前"24 条曲线"来自 T13 默认目录，不是本 run（`714ad69`）。
20. **计时污染守卫**：并发跑回归时测出 `p95=158 ms`、安静时 **16.7 ms**（12.8×）；
    新增 `timing_suspect`（p95/p50 > 4× 判可疑 → 记 None 并说明），不把"机器在忙"
    当模型缺陷（`16b03f5`）。
