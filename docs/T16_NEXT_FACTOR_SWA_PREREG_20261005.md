# T16 单因子预注册：检查点平均（SWA）能否修掉弱 seed（2026-10-05）

- 动机：R2 在 v8 定义下**只差 seed 45 一门**（dev 漆召回 5/6，0.6728，差 0.026），
  已实测为**不可约 per-seed 方差**（非训练不稳定/非 checkpoint 选择/非剂量）。
  检查点平均（对末 k 个 epoch 的权重取平均，SWA）是**方差缩减的标准手段**，
  且**不动数据、不动协议、不动训练预算**。
- **若成立**：R2 可在**方案自己的 strict 规则**下、v8 定义上两套集合全过 →
  链条解锁只剩"是否采纳 v8 定义"一个决定（不再需要签核 `mean` 规则变更）。

## 1. 因子与口径（单因子）

| 项 | 值 |
|---|---|
| 因子 | 评测用检查点：**末 5 个 epoch 的权重平均**（SWA-5）vs `checkpoint_last.pt` |
| 不变项 | 数据、init、480 步、种子 42–47、`--deterministic`、协议、膨胀=0 |
| 训练 | 用**同一条已记录命令**（`round0_commands.json` 的 candidate）重跑 6 seed，**加 `--save-every-epoch`**，输出到新目录（不碰既有臂产物） |
| 评测 | `scripts/m5_r2_verdict.py --recall-scope paint --verdict-mode strict`（方案既定规则）+ R3 受限类 |
| 安全前置 | **负例假线率不得上升**：结构负例包 + 无线场景帧，SWA vs last 的 `negativeFP` |

## 2. 判据（先定后跑）

1. **主**：SWA 下 dev 漆召回 **6/6 seed ≥0.70**（即 seed 45 ≥0.70）且其余四门不劣化
   （覆盖率 ≥0.80、身份率 ≥0.60、精度 ≥0.40、角色 ≥0.70，逐 seed）；
2. **次**：R3 受限类五门仍 6/6；
3. **安全前置**：负例假线率不高于 last（逐 seed 比较）；
4. 任一不满足 → 如实记录为**否决**（并把 SWA 的收益/代价量化，供后续参考）。

## 3. 已知先验（seed 42 探针，v8+1px）

| 检查点 | 精度 | 召回 | IoU | 路外 FP |
|---|---|---|---|---|
| SWA-5 | 0.7184 | **0.8069** | 0.6130 | 28 741 |
| last | 0.7524 | 0.7789 | 0.6200 | 18 185 |

→ 单个强 seed 上：**召回 +0.028、精度 −0.034、IoU −0.007、路外 FP +58%**。
所以本因子**不是"白拿"**；弱 seed 是否获益、负例通道是否受损，都要按 §2 实测。
