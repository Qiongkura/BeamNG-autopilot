# T16 多族线分割重训预注册：跨族留出协议（2026-11-02）

## 目的

认证池扩到 10+ 站点族（目标 15 族）后，用**跨族留出**协议重训线分割模型，
回答"跨族 line IoU 能否从 0.0 抬起来"。首训（5 族/15 帧）已量化：
内部 val 0.77 / 同族 0.30 / 跨族 0.0000（`T16_LINE_SEG_RETRAIN_RESULT_20261102.md`）。

## 数据

认证池 = 各扩量批次 engine_verified 导出族目录（`m5auto_*/front_main`），
每族 3 帧。当前在案：

- batch1（offset0）：a3、a4
- batch2（offset5）：a0、a3、a4
- offset15：a2、a3
- offset20：a0、a2、a4
- （offset25/30 批次完成后追加）

## 划分（分组留出，防跨族泄露）

- **3 折分组**：按批次分组，留出 1 折的族（≈1/3 家族、9-15 帧）评测，
  其余 2 折训练；三折轮转，**宏平均 line IoU** 为主指标。
- 族内帧级 split-gap 0.5 s 仍生效；同族帧绝不跨训练/评测（同族=同路段同光照）。
- 训练配置同首训：random 初始化、40 epochs、batch 8、lr 1e-3、line-weight 2.0、
  paint-source engine_annotation、CUDA；增广全开（现有光度/几何）。

## 判据

- 主指标：三折宏平均 `line_iou_near`（m5_eval_seg 同口径）。
- 对照：首训跨族 0.0000 / 同族 0.2975；任何 >0 的跨族值都是进步，但仍受
  小池噪声约束——宏平均 + 逐折值都要落盘。
- **不晋级**：晋级需更大池与开发门复审；本轮仍是研究数据点。

## 纪束

不降门、不消费最终集、无人工标注、不晋级；模型与三折评测报告哈希归档。
