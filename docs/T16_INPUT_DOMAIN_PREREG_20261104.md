# T16 输入域匹配臂 · 预注册（2026-11-04）

## 1. 背景与机制

live 回放（`T16_MARKING_REPLAY_RESULT_20261104.md`）：east 19 帧中 **18 帧
H-M0**（语义掩码里没有右侧黄线），投影距离验证左线 2.7–6.8px、右线
16–50px——不是投影假象。而池域同场景（原生 192×144 帧，模型内部
INTER_AREA 放大到 536×403）raw 黄召回 0.94。

训练/池域管线是 `192×144 --INTER_AREA--> 536×403`；live 是 536×403 原生
直送（`_infer_logits` resize 536→536 为恒等）。模型未见过原生 536 的锐利
细黄线，这是 east 掩码缺失的最可能机制。

## 2. 假设与臂

- **H-In**：把 live 帧先按 INTER_AREA 缩到 **192×144** 再送入模型（模型
  内部再放大到 536），可恢复 east 的右黄线掩码与候选。
- **臂 D**：`--input-width 192`（研究开关，默认 None=现行行为）。实现：
  帧缩到 (192,144) → `seg.predict` → 掩码 nearest 放大回 536×403 →
  `detect_lines`/`pair_lane_markings` 在原始帧几何上继续（相机模型不变）。
- 不做：不改模型、不训练、不改默认门、不新增标注。

## 3. 装置

- 已保存帧：east 19 帧（余量 1.0）、west 24 帧（余量 0.6），
  `marking_replay_*_r0.frames/`（含 pos/heading/CameraModel）。
- 工具：`scripts/m5_marking_replay.py --input-width 192`；分类与 GT 逻辑
  与回放诊断完全一致（H-M0/M1/M2/M3/ok）。

- **P-In1（主）**：east 的 **H-M0 比例 ≤0.3**（基线 18/19 = 0.947）。
- **P-In2（主）**：east 的 **ok 比例 ≥0.5**（基线 1/19 = 0.053）。
