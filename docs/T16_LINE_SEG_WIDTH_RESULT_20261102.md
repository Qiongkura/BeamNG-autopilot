# T16 容量臂结果：width 1.25 噪声内、1.50 负收益——训练侧搜索空间收口（2026-11-02）

## 执行

SegUNet 的 width 链路（训练 --width、评测从 checkpoint arch_args 自动读容量）
本就贯通（既有回归测试）；本轮补齐 SSL 脚本的 --width 参数化（编码器容量
与微调模型一致）+ 回归测试（44 通过）。容量臂：width 1.25/1.50，各 4 折
× 种子 42/43，SSL σ0.05/20ep 同步容量。

## 判读

1. **容量臂同样未跨过种子噪声**：w1.25 种子间反向（+0.041/−0.047）、
   w1.50 两种子皆负。折 A（早期 utah）继续是噪声主源（0.27–0.38）。
2. **训练侧搜索空间正式收口**：监督 8 臂 + SSL 超参 3 臂 + SSL 帧扩量 +
   容量 2 臂 = 14 个变量全部证伪；唯一确认收益 = SSL 编码器预训练
   （σ0.05/20ep，配对 +7.5%，2/2 种子）。
3. 本过程留存的最高水位：**跨族 line IoU 宏平均 0.4787（种子42）/
   0.5148（种子43）**，模型不晋级。
4. 剩余路径（需新资源/新工程）：真实相机域数据；线专用架构（如长条
   感受野/条带注意力）；或把 SSL 用到部署链路（分割器实际消费的模型）。
   UI 上的"顶尖"距离（最弱折 ~0.27、宏平均 ~0.5）在本数据规模下未变。
