## 1. 研究问题

在 `fixed_actual_pose` 契约与等曝光协议下，**起点位姿**本身（生产实际放置的 baseline 起点
vs 沿航向前移后的生产实际放置起点）是否改变驾驶读数：被接受路径帧率、净行进、
感知车道来源与安全仲裁原因分布。

这是对 2026-10-11 反向标定观察（1/1 qualified 偏移点）的收口：把「契约可实现 + 偏移点可测」
升级为**两臂各 2 次重复的等曝光起点对照**。它仍是单地图单路线的探索性因果对照。

## 2. 臂定义（冻结）

**几何事实（预注册声明）**：以 B 的航向为基准，O 位于 B 前方 **7.853 m**、左法线方向 **0.003 m**、
航向差 **+2.189°**。偏移方向是**沿航向（along-track）**，不是路面横向；O 的位姿包含生产对齐
的旋转与漂移。因此本轮结论只按「起点位姿（位置+航向的打包差异）」层面解释，
**不写「横向偏移剂量」**，也不写「+5 m 横向」。

## 4. 重复与顺序（预注册）

每臂 2 次，共 4 次运行，顺序：**O → B → B → O**（两半镜像，平衡会话顺序与热身效应）。
放置是确定性的；重复捕捉会话级差异，不承诺种间随机化。

## 6. 分析规则（预注册）

- 主读数（逐 run 报告）：accepted-path 帧数/帧率、净行进、最大速度、曝光跨度、
  感知车道来源帧数、仲裁原因分布。
- 先看同臂两次重复的一致性；两臂比较按逐 run 并列呈现，不合并平均掩盖重复间差异。
- 曝光不等价的 run 不进入并列比较，只按原样报告失败原因。
- **不声称**：安全性、泛化、模型收益、路径可行性定理。样本量 4，单地图单路线，
