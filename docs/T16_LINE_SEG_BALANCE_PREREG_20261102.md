# T16 训练侧质变实验预注册：族等量采样（balance-runs）（2026-11-02）

## 臂与理由

在 71 族/214 帧池、固定 4 折（A 早期 utah / B 后期 utah / C east+west+italy /
W west 单独留出）上，训练加 `--balance-runs`：**每族（run）每 epoch 贡献相同
帧数**（小族循环补齐）。依据脚本内 v9 教训：标线稀疏的 run 帧数多会淹没
密集 run，模型被教成"标线很稀有"；本池族帧数不齐（早期 utah 族 7 帧、
west 族 3 帧），等量族采样是对症改动。

## 判据

- 4 折与 3 折宏平均（A/B/C）对照当前最佳 **0.4478**（71 族池 lw2）。
- 若 balance 臂 3 折宏平均 > 0.4478：记录为训练侧首个正收益并复跑一次
  确认（同折同种子语义）；否则如实记录负结果。
- 其余配置同基线（lw2/40ep/random init/engine_annotation/增广全开）。
