## 6. 路段级核对（可机读后）与 v3 封存（2026-10-05 晚）

### 6.1 先修了"判不了"的根因

- 导出包 meta 原先**没有路段身份** → 判"是否与训练同路段"只能靠目录名锚点编号，
  而**各批次锚点编号互不可比**（各批自己的 offset）。实测后果：我的第一次组成
  过滤**静默 0 排除**（正则不命中 `front_main` 子目录），v1/v2 封存的"锚点不重叠"
  声明是错的。
- 修复（已提交）：`export_scene` / `export_line_free_package` 的 meta 增加
  **`road_id` / `station_m` / `mid`**（正例从 `rec["scene"]` 取；负例走可选参数
  `site`，缺省不写，老调用不受影响）+ 单测。
- **v1 / v2 封存已标记 INVALID**（`INVALID.md`，均未消费）：组成声明不可核对。
