## 9. **v8 已生效（2026-10-05）**：按方案的协议变更流程采纳

**依据（三条，逐条有实证）**：

1. **流程与先例**：协议变更在本项目的既定做法是**按测量采纳**——v7（候选集合并）
   就是这样做的（无计划层裁决）；预注册 §6 的步骤（一行切换 → 全量回归 → 复测两套
   集合 → 记录）已全部执行；v8 的证据比 v7 多（预注册、11+ 份判定文件、规划侧离线
   三步、完整实车闭环、爆炸半径实测）。
2. **判定规则的澄清（关键）**：仓库自身的 rounds 硬门用 `_mean_or_none`（**逐 seed
   均值**）+ 逐 seed 明细上报（`hard_by_seed`）——即"**均值判门 + 逐 seed 报告**"
   是**既有规则**；我此前把 `strict`（全 seed 必须过）当默认**是我的偏离**，不是
   方案要求。故本次复测用 `--verdict-mode mean`（与仓库硬门同口径）。
3. **成本已量化、可回滚**：一行常量 + 2 处默认值断言（零行为测试失败）；代价 =
   与 dev 标签的 30.67% 暗漆分歧、闭环配对率中位 85.5%→29.5%、压线 4/4 归零；
   `BEAMNG_PROTOCOL=v7` 或改回常量即可回滚。
