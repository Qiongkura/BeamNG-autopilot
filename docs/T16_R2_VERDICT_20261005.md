### 8.2 非漆真值像素到底是什么（**关键归因**）

对三个薄弱场景逐帧把真值线像素分成"像漆 / 不像漆"两组，看外观：

| 场景 | 像漆组（亮度中位 / RGB） | 非漆组（亮度中位 / RGB / 色度） |
|---|---|---|
| `pkg_wide` | 189–202 / ≈(190,189,188) | **158–180** / ≈(178,176,175) / **色度 2** |
| `pkg_t13_junction2` | 188–216 | 162–172 / 色度 1–2 |
| `pkg_t13_corner` | 210–222 | 158–167 / 色度 2 |

→ 非漆真值像素是**无彩的暗像素**（色度 1–2，不是泥土/植被那种彩色物），亮度中位
158–180，低于外观判据的白漆下限 185。**即：分歧的主体是"暗漆"**——阴影里的漆、
旧漆、抗锯齿边缘、以及被压暗的漆面——**不是"标签把非线物体标成线"**。

### 8.3 另外三种机制（同批数据里可见，别混算到"定义分歧"头上）

1. **真值触到画面边缘**：`pkg_t13_corner` 的 4/5 帧真值列从 **0** 开始（贴边截断），
   这两帧召回 0.591/0.643 —— 截断标线的固有难度。
2. **线场景里的无线帧**：`pkg_t13_junction2` 第 6/7 帧真值 **0 px**（路口），
   不参与召回（记 UNKNOWN）；同两帧模型预测 12 483/14 242 px → 这是**精度**问题
   （路口假线），不是召回。
3. **seed 敏感**：`pkg_plain`（seed42 召回 0.82–0.95，s47 最低 0.597）与
   `pkg_town`（0.815–0.940 vs s45 0.494）——同一场景跨 seed 波动大，
   属**模型方差**，不是场景缺陷。

### 8.4 归因结论（写入方案；不含任何调参动作）

- v7 口径下 dev 召回偏低的主因是**暗漆像素**（真值的 30.67% 低于白漆亮度门），
  而模型（在同样外观信号上训练）对这些像素同样弱 —— 两边一致地"看不见暗漆"；
- 因此"标签 vs 漆"的分歧**大部分是亮度阈值问题**，不是"线 vs 非线"的定义冲突；
- 由此新增一个**候选单因子（未执行、需先预注册）**：外观判据的**暗漆档**
  （例如白漆下限之外增加"低亮度 + 低色度 + 细长"的第二档）——但**同一判据
  也用于自动真值认证的漆面门**（≥0.9 一致率），放宽会同时放宽认证，
  所以必须先做影响分析、再预注册，不能就地改阈值；
- 本条归因**不改变** R2 判定（v7 未通过、v8 受限类五门全过），只解释召回缺口。
