## 3. 结论（写入方案）

1. **R2 在当前（v7）口径下未通过**：身份率 0/6 + 召回 4/6（逐 seed 口径）。
2. 在 v8 口径下 R2 也未通过，但**只剩一个定义性门**（标签范围召回），
   漆范围召回 5/6 通过。
3. 因此 R2 的结论取决于**"线"的定义**：
   - 若定义 = 人工标签（v7）：R2 未过（两门）；需按决策记录 B 把身份率记为约束，
     并**同时记录召回在 2/6 seed 的跌破**（新信息）；
   - 若定义 = 铺装上的漆（v8，选项 E）：R2 在定义内为**四门过 + 召回按漆范围
     5/6 过**，与标签的 30.67% 差异作为定义外分歧单报。
4. **最终集独立确认（一次性）与 Tech 驾驶在 R2 未通过前不得启动**；
   规划侧闭环行为验证（多车道配对/暗漆漏检）单独一轮。
5. 生产默认仍是 v7（未切换）；v8 的切换按预注册 §6，等计划层裁决。
