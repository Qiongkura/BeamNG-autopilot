## 判定（预注册 R1–R3 / H0）

- **R1（east/m1.0 右线召回 ≥0.6）：全部失败**。臂增益最大 +0.08（yellow/
  east_prior）、east_hard 上为负；远低于 R1 与证伪阈值（<+0.2）。
- **R2（east/m1.0 true ≥0.8）：失败**。本轮基线已 0.91（见方差说明），三个臂
  反而降到 0.50/0.40/0.03，phantom 升高。
- **R3（west 控制不回归）：通过**（三臂均 1.00，0 变化）。
- **H0 成立**：黄线阈值（Y1）、thin 最小跨度（S1）、CLAHE 光照归一（I1）
  都不能把右线召回从 ~0 拉起来 → **损失在语义掩码/检测层，不在候选层**。
  west 控制场景的三臂零效应进一步排除了"环境开关本身改变行为"的混淆。

## 重要方差警示

east/m1.0 的基线 true_rate 在两次批之间从 0.326（薄线召回批，2 重复）跳到
0.91（本批，2 重复；单轮 0.88/0.94），且黄线/span 臂出现单轮 0.00 与 1.00
并存——该场景的配对结果**双稳态**（可能取决于引擎启动时的光照/云层随机）。
因此：
1. 单轮对比不可信，本批所有结论只用 2 重复均值 + 跨批一致性判读；
2. "右线召回≈0"在**所有臂、所有轮、两批**中一致，这一结论对方差稳健；
3. 后续任何"难场景"实验都必须先做 3+ 重复的基线稳定性检查。

## 结论与下一步

- 候选层三臂不晋级、不进默认；环境开关保留（默认关）供后续复现。
- 下一课题（需新预注册）：**语义掩码侧的右线（黄线）诊断**——用
  `mask_counts` 与投影 ROI 检查"掩码里到底有没有黄线像素"，区分
  (a) 模型完全没检测到、(b) 检测到但在后处理/外观门被删；若是 (a)，则属于
  模型/数据域问题，需要数据授权或真实域数据，不在本 recipe 内。
