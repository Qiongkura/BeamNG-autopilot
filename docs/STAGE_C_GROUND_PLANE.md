## 3. 记录里必须点名的两个缺陷（我自己的度量）

1. **"出铺装"与"压线"是同一个信号数了两遍**：20 次跑（每臂 10 次）里 `off_pavement_frames` 与
   `body_cross_frames` 的帧集合**逐次完全相同**，而且与 `lat_left` 有值的帧几乎一致
   （20 次跑里 `lat_left` 有值帧与 `body_cross` 帧集合也几乎一致）。抽查帧显示驱动量是
   `road_off=1.604`（感知越界距离），而 `lat_left=None`。所以这三列**不是互相独立的检查**，
   而是"感知边界撤销"这一个事件的三种记账。计划 §7 要求的独立真值版本（人工标注/地图真值）本轮**没有**。
2. **`damage=0` 不能当安全证据**：20/20 次都是 0，但这 20 次里车几乎没动（里程 0.6–5.7 m，停车 15–19 s）——
   计划 §9 明令不得用单次（这里是多次）`damage=0` 证明安全。本轮只把它当"没有记录到碰撞"。

## 4. 结论与动作

- **无可测增益**：里程、停车秒数、`no_drivable_path` 秒数的分布几乎重合；唯一稳定差异是
  `lane_sensor_rate`（0.635 → 0.400），方向上对 B 不利（感知车道更常不可用）。
- **撤回 n=1 的说法**：我在 T05 与 `GEOMETRY_BASELINE.md` 里写过"打开它把 `lane_drivable.frac`
  从 0.75 拉到 0.50"。n=8 后该效应**反向且被噪声吞没**（A 0.791 vs B 1.000，两臂区间都覆盖 0–1）。
  那句话按计划"不能把 n=1 当信号"的纪律**已更正**。
- **默认保持关闭**（`BEAMNG_GEOM_GROUND_PLANE=0`，仓库原状未改）：计划 §6 阶段 C 退出门是
  "没证明增益的变更不进入下一阶段"，本项即按此处理——**执行了对照、结论是不采纳**，这本身是阶段 C 的合法结果。
- **ODD 说明**：本路段是**停走主导**（里程 1–5.7 m/20 s），所以这次对照只能就"证据门是否更宽松/更紧"发言，
  **不能**就驾驶行为、压线或安全发言；压线/出铺装的独立真值版本需要标定路段与人工核对帧（列为下一项）。
