## 判读

1. **泛化谱系已量化**：内部相邻帧 val 0.77 → 同族实际 0.30 → 跨族 0.0。
   内部 val 被相邻帧（0.5s gap）抬高，不是泛化证据。
2. 现有光度/几何增广已覆盖外观轴仍跨族 0.0 → **增广不是瓶颈**；数据广度
   （站点族数/地图数/光照条件数）是绑定约束。5 族/15 帧不足以学到可迁移的
   标线外观。
3. 对 v13b 基线 0.116（39 帧旧语料多场景 holdout）的对照：**非同集、不可
   声称超越**；本轮模型在跨族留出上 0.0，坦白记录。
4. **模型不晋级**（预注册即声明）；权重与评测留档。
