4. **A′ 表面口径几乎零代价**（R3：身份 0.9385、`matched_lost` 0–1；dev 同口径
   0.7717、代价 40–53）→ 这些候选与真线无关。
5. **角色门缺口的一半是重复检出**：匹配上但角色不一致的 14 个候选，与同侧

   1.71 m。v7 的合并处理的是**共线碎片**，抓不住这种**并行重复**。

## 2. 候选单因子（按代价排序，均"一次只动一个"）

### A. 经典通道的横向合理性门（提取侧，最小改动）
- 内容：经典候选（`learned_frac=None`）的 |lat| 超过 `L_max` 时不产出。
- 先离线扫描（不改代码）：用 dev + R3 帧，对 `L_max ∈ {3.0, 4.0, 4.5, 5.0, 6.0}`
  出**收益/代价表**（杀掉多少未匹配、丢多少匹配）。
- **已知风险（必须先看数）**：dev 里有 40 个**匹配**候选在 |lat| ≥ 5 m（宽路多车道
  的真线）→ 纯截断会杀真线，收益可能被召回损失抵消。若收益/代价比不成立，
  本选项直接否决，不做训练实验。

### B. 远场路外结构负例（学习侧，数据通道）
- 内容：在宽路锚点上放 |lat| ≈ 5–8 m 的结构（墙/护栏/杆），生成新负例包。
- **先验预期低**：现有结构负例就放在 `±(半宽+0.9/2.6 m)`（宽路上即 5–7 m），
  6× 剂量已是实测峰值（>8.5× 转差，§25）→ 同一通道再加量的期望增益小。
- 仅作为**对照臂**（确认"再加量无效"），不作为主推。

### C. 并行重复合并（提取侧，协议变更候选 = v8）
- 内容：在 v7 共线合并之外，新增"同侧 + 横向 |Δlat| ≤ 0.5 m + 像素行重叠"
  的并行重复合并。
- 先离线扫描（像 v7 那样，不训练）：在 dev + R3 上量**去重收益**
  （角色一致率、身份率）与**召回代价**（`matched_lost`），再决定是否升协议。
- 预期：直接消掉 10/14 的角色不一致；对身份率是间接增益（重复的外侧副本
  常常正是未匹配的那个）。

## 3. 测量计划（选定后执行，口径冻结）

- 固定 init / 480 步 / `--deterministic` / 种子 42–47 配对；主指标
  **身份率（v7）+ 角色一致率**，同时报 C/R/M/L/A、`off_road_frac`、
  `identity_surface_scope`（只报不判）。

  `DOSE_SAFE_FRAC=0.15` / 负例 6× 上限。
- **不放宽任何门**；缺测记 UNKNOWN。
- 若选项 C 入选：先跑离线去重扫描 → 若收益/代价成立，再预注册协议 v8
  并做全臂重测（旧判定不可比）。

### 5.3 结论与建议（给计划层的选择）

1. **lateral 是身份率门的唯一已验证杠杆**，但它的代价落在**召回/覆盖**上，
   且 dev 与 R3 的代价量级差很多（dev 丢 55% 匹配候选，R3 丢 0）。
   → 建议**先实现到提取侧（env 开关，默认关）并用像素级五门 + 6 seed 配对实测**，
   再决定是否升协议 v8。**不建议**在没有像素级召回数据前直接切默认。
2. **parallel 是角色率门的杠杆**，代价小、机制清楚（并行重复），建议与 lateral
   分开评估（一次只动一个）。
3. 两者都属**候选集口径变更**（同 v7 的性质）→ 升协议要按纪律做全臂重测，
   旧判定不可比；且必须先写预注册（含 L/d 的选值与停止条件）。
4. 路面幻影（§1.3 的 19/113）在 lateral L≈3–4 时**不会被清掉**（它们在
   |lat| < 1.2 m）→ 若 lateral 采纳后身份率仍不达 0.60，下一个单因子就是
   幻影（阴影/接缝边界的形状或外观判据）。

### 6.3 像素级代价：**零**

### 6.4 结论与必须记录的代价

- **身份率是最大杠杆**：dev +0.25、R3-b +0.31，两个集合、全部 seed 都过 0.60；
  dev 上同时过覆盖（0.91）与角色（0.84–0.88）。
- **代价 1（R3-b 覆盖）**：候选集缩小使覆盖（R/C）从 0.80–0.86 掉到 0.74–0.81

- **代价 2（冻结门量不到的功能损失）**：dev 上 L=3.0 丢掉 **88/160 个已匹配候选**
  （宽路多车道的真·远线）——像素门看不见它们，但**多车道配对/规划**会用到。
  采纳前必须复核规划侧行为（安全相关），并把这条写成协议 v8 的已知代价。
- **代价 3（口径性质）**：这是候选集**范围**变更（同 v7 性质）。按纪律要：
  ① 预注册（L 选值与停止条件）；② 全臂重测确认**臂排序不被反转**
  （§10.3 的 A′ 就是因排序反转被否）；③ 旧判定不可比。

### 6.5 给计划层的建议

1. 若接受"候选集范围 = 相邻车道（|lat| ≤ 3–4 m）"这一**功能性定义**，则
   lateral 是当前唯一能把身份率门验出来的杠杆，且像素级零代价；
   建议按协议 v8 走完整流程（预注册 → 全臂重测 → 规划侧复核）。
2. 若不接受（要保留远线候选），则维持 v7 + 决策记录 B 的框架，身份率门记为
   候选集约束，R2 以该口径推进。
3. 无论哪条，parallel 合并（§5.2，角色杠杆，身份中性）可作为**独立**的第二个
   单因子，不与 lateral 混在一起评。

### 7.4 仍未过的门：像素精度（与候选集无关）

R3-b 像素精度 0.3795–0.4443（4/6 seed 不过 0.40）。它来自**分割掩码**的

### 7.5 更新后的建议（给计划层）

3. 若计划层不接受候选集范围变更，则维持 v7 + 决策记录 B；本节的测量仍成立，

4. 采纳顺序：先预注册 v8（含 L=3.0 与合并补齐的定义、停止条件）→ 全臂重测
