## 判读

1. **预注册最终判据未达成**：宏平均 0.2723 < 0.2792，lw4 不是可迁移增益
   ——折 A 的提升在折 C 完全反转（折间方差主导，池仍太小）。按预注册
   "否则原结论保留"：**lw2 宏平均 0.2792 仍为当前最佳**。
2. 数值旋钮的边界已探明：80 ep 过拟合（−0.084）、lw1 欠监督（−0.133）、
   过采样负收益（−0.050）。剩余训练侧杠杆：多尺度增广（需代码臂）、
   更长池/更多族（数据侧）。
3. 模型不晋级（研究臂）；fold 方差（0.195–0.386）本身是"顶尖"距离的核心
   指标——池规模是主瓶颈，不是旋钮。
