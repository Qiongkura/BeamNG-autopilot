## E1：后处理因素拆分（三个开关）

**目的**：把表 I／表 II 里「后处理 + 范围」混合的差异拆成三个开关各自的贡献。

**配置**（每项一次运行，6 个种子）：

| 代号 | 横向范围 | 同侧合并 | 外观门 | 环境变量 |
|---|---|---|---|---|
| C0 = v7 | 关 | 关 | 关 | `BEAMNG_PROTOCOL=v7`（**必须显式**：代码默认已是 v8） |
| C1 = +lat | 5.5 m | 关 | 关 | `BEAMNG_PROTOCOL=v7` + `BEAMNG_LINE_LAT_MAX_M=5.5` |
| C2 = +merge | 关 | 开 | 关 | `BEAMNG_PROTOCOL=v7` + `BEAMNG_LINE_MERGE_FINAL=1` |
| C3 = +appgate | 关 | 关 | 开 | `BEAMNG_PROTOCOL=v7` + `BEAMNG_LINE_APPEARANCE_GATE=1` |
| C4 = v8 | 5.5 m | 开 | 开 | `BEAMNG_PROTOCOL=v8` |

**读数**：每个配置报 ① 标签范围召回/精度、② 漆范围召回/精度、③ 真值像素保留比例、④ 三个候选级门（覆盖率/身份率/角色）、⑤ 负例一侧假阳性帧率与像素比例。

**一致性检查（执行前固定）**：C4（v8）重跑的 dev 均值必须复现既有判定文件`r2_verdict_v8_ADOPTED_20261005.json` 的 dev 行（精度 0.894、漆召回 0.812、角色 0.883）；不一致则停止实验、先查环境。实测：复现（见结果文件）。

**读数规则（事前固定）**：
- 只做描述性对比：报告每个开关单独开启相对 C0 的变化量（逐种子差值 + 均值），**不做显著性声明**（n=6 种子、单池）。
- 任一开关若使某个冻结门从通过变为不通过，照实报告，不因此调整采纳协议（v8 已冻结，本实验不改判定）。
- 漆范围与标签范围的差异单独列出，不与后处理效果相加。

## E2：等种子剂量对照

**目的**：检验「6× 是峰值」在等种子条件下是否成立。

**配置**（四档剂量 × 同一批种子 42–47，配对）：

| 剂量 | 检查点目录 |
|---|---|
| 0×（基础） | `t16_negdose6x_20261001/baseline/seed{42..47}` |
| 4× | `t16_negdose4x10s_20261001/round0/seed{42..47}` |
| 6× | `t16_negdose6x_20261001/round0/seed{42..47}` |
| 8.5× | `t16_negdose95xc_20261001/round0/seed{42..47}` |

**读数**：每档的身份率（主）、角色一致率、覆盖率，逐种子值与均值、最小–最大范围，以及**逐种子的配对差值**（相对 0× 档）。

**读数规则（事前固定）**：
- 峰值结论成立的条件：6× 的**逐种子配对差值**均值大于 4× 与 8.5× 的同口径差值，且 6× 的逐种子值在 4×/8.5× 的逐种子范围内不重叠或重叠很小。
- 不满足上述条件时，论文的剂量结论降级为「已观察到的最高单次读数位于 6×」，并在正文与局限中写明。
- 不因结果改变交付候选（确认已在 6× 上消费；改变交付臂需要新的封存集，本轮不做）。
