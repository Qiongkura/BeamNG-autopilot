> 本文把总目标拆成可判定的阶段；每阶段列「交付物 / 判定标准 / 现状 / 工作量 /
> 依赖 / 不要重走的坑」。里程碑沿用 README 的 M1–M6 编号，当前工作属于 **P0**
> （README「感知车道连续性」一节之后的攻坚轮）。

## P0 — 横向参考单一 owner + 车道连续性（进行中）

* **交付物**：`lane/` 单 owner 策略、虚线归并（17× 提速、默认开）、逐门探针、
  `scripts/m5_live_ab.py` 降方差协议、`scripts/m5_seg_task_eval.py` 任务口径。

## P1 — 把双侧成对率抬上去（唯一能降 stall 的路）

* **目标**：让「有两条真实边界可配」的帧从 18.8% 显著上升，使长间歇不再出现。
* **两条子路线**：
  * **P1a 人工标注（决定性成分，有量化先例）**：27 帧城镇真值就把成对率 0.6%→11.1%；
    v13b 的手工城镇标线再 +9.1 pt。**需要人涂画**：每批 ~20 帧约 20–40 分钟，
    可用 `--prefill-model` 预填（预填必须人工修正）。我每轮 1.5–2 h（训练 + 任务
    指标选点 + 同会话 A/B），现实预期 **2–3 轮**，且不保证越过 v13b。
  * **P1b 新检测/配对方法**：非「调参」类的新想法（如跨帧几何延展、以成对率为目标的
    损失/后处理）。当前所有调参路径已排除（见下），收益未证。
* **判定标准**：在**钉住 10 集**（`logs/m5_seg/pinned_town_set.json`，09-05 →
  09-11 等间隔 10 集，2026-09-12 固化）上，`m5_seg_task_eval.py` 的
  **paired 显著超过 33.1% 且 in-lane ≥ 86%**（均为现 pin `seg_model_hand` 在
  同一钉住集、**修正后目标 EGO_LANE_CENTRE_M=0** 下的基线，见
  `lateral_reference_diag` §22；旧口径的 "24.3% / 26%" 不可比，作废）；
  随后实车 A/B 使 `stall` p50 ≤ 83。
* **依赖**：P1a 需要你；P1b 需要实车窗口。
* **不要重走的坑（都已实测排除）**：
  * 换 checkpoint（v8 IoU 领先但成对率 7.9%；§12）
  * 窄配方重训（v22 paired 12.0%；§13）
  * 全量配方 ± 城镇真值（0.6% vs 11.1%；§15）
  * 全量 + 逐轮任务早停 + in-lane 门（最好合格 epoch 16.7%；§16）
  * 控制侧「缩短重新捕获代价」（无滞后，p50 0 帧；§19）
  * 放宽候选门 / 放行 `unknown:kind`（中位 GT 重叠 0.00，仅 1% 像边界；§20）
  * 降 span 门槛、放开提取器守卫、时序 hold（跨不过 50 s 空档）

## P2 — 无车道时的降级更「有用」（可选，需先改判定口径）

* **目标**：铁律不许回退地图横向，但在**长**无车道段（50 s 级）允许**有界的合法降级**
  （AGENTS.md 允许：刹停 / 保持当前航向直行 / 落到路面安全点），把「原地停」变成
  「低速沿当前航向到安全点」，从而不把 `stall` 计成失败。
* **判定标准**：无车道段内 `crossC/crossR/off` 仍为 0；车不越界、不进对向、不倒车。
* **注意**：这**不提高安全性**，只是改「失败模式的表现」；必须先与你确认验收口径
  （否则等于把指标做好看）。当前实现是**停**，改之前需要你点头。

## P3 — 场景泛化与回归保护

* **目标**：pin 是**分场景**的，山地/桥/海岸不能因城镇模型而回退。
* **交付物**：`m5_fsd_benchmark.py` 各场景 pin 与理由；每次换 pin 必跑「其他场景不退化」。
* **判定标准**：mountain/bridge 的 paired 与安全项不低于换 pin 前。
* **依赖**：实车窗口（每场景 ≥3 臂）。

## P4 — 从「验证入口」到「主驾驶」（README 已知缺口）

* **目标**：README 记录「FSD 栈默认不驱动，`AutopilotSession` 仍走 M5 规则驾驶」；
  把 FSD 栈切为城镇/山地的默认驾驶路径，旧规则栈降级为兜底。
* **交付物**：切换开关 + 逐场景默认值 + 回退路径；`m5_gui_smoke` 覆盖。
* **判定标准**：默认路径下城镇 `crossC/crossR/off = 0`、`stall ≤ 83`（即 P1 达标后）；
  山地连续路线无倒车/无上草。
* **依赖**：P1 达标（否则切过去只是更慢的蠕行）。

## P5 — 数据与标注流水线工业化

* **目标**：把「标注 → 训练 → 任务口径选点 → 实车 A/B」做成可重复的一键流程。
* **交付物**：`--task-eval-every`/`--task-min-in-lane`（已有）+ 标注批次命名规范 +
  任务口径的固定 episode 集（`--episode-names`，否则跨时间不可比）。
* **判定标准**：任一新模型能在 1 条命令内给出「paired / in-lane / 实车 A/B」三段结论。

* **模型产物不在仓库**：pin 指向 `logs/`（gitignore），换机器/换人即失效。

  ≥5 臂/组、同会话交错、固定 episode；跑前在 `docs/HANDOFF_20260911.md` 留
