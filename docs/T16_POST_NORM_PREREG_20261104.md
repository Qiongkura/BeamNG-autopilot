# T16 后处理分辨率归研究臂 · 预注册（2026-11-04）

## 1. 背景与机制

`T16_RESAMPLE_DIAG_RESULT_20261104.md`：同一池帧按 536×403 预上采样输入时，
east 的 raw 黄线召回 0.973 但 **post 只有 0.103**（native 0.727，−62.5pp）；
west 变化 ≤5pp。机制：`Segmenter.predict()` 的后处理（形态学、路面约束、
连通段/外观门）在**输入帧分辨率**上运行，核大小/膨胀/跨度阈值是**像素固定
值**，因此池域（后处理在 144）与 live（后处理在 536）行为不同，细黄线在
536 被删掉——这是 live 右线候选召回≈0 的直接机制。

## 2. 假设与臂

- **H-P**：把后处理放到**规范分辨率**（144 宽）上跑、再把掩码放大回输入
  分辨率，可恢复 536 输入下的黄线存活，且不破坏 west 的正例。
- **臂 P1**：`Segmenter(post_norm_width=144)`——研究开关，**默认 None =
  现行行为**；实现为 `_postprocess` 包装：帧与掩码 nearest/area 缩到
  144×(按比例)，跑原 `_postprocess_core`，结果 nearest 放大回原分辨率。
- **不做**：不改核大小常量、不改默认、不训练、不新增标注。

## 3. 装置与指标（离线，只读）

- 数据：east off45 `a0s0`/`a1s0`/`a2s0`（9 帧）、west off40 `a3s0`（3 帧）；
  模型 pin `seg_model_v28_sslA`。
- 条件：`--compare-resample --post-norm-width 144`；与无归一的同条件结果
  （已存 `resample_diag_*.json`）配对比较。
- 指标：post 黄线召回（主）、raw 黄线召回（不变性 sanity）、白线召回、
  post 线像素数、`drop_frac`。

## 4. 判据（跑前冻结）

- **R1（主）**：east 的 **cubic 条件** post 黄线召回 **≥0.6**（无归一时 0.103）。
- **R2（控制）**：west 的 cubic 条件 post 黄线召回 **≥0.84**（无归一时 0.843）。
- **R3（不变性）**：raw 黄线召回变化 ≤3pp（归一不应改变模型输出）。
- **证伪**：R1 不达 → 后处理分辨率归无效，记录为需要改核大小/形态学策略
  的新课题；R2 失败 → 归一破坏正例，不采用。
- 场景差异不取平均；east/west 分别判定。

## 5. 纪束与交付

- 研究开关默认 None，单测钉住默认；不改生产默认门；
- 交付：本预注册（跑前入库）、实现 + 单测、`T16_POST_NORM_RESULT_*.md`、
  JSON 与证据 zip。若 R1/R2 通过，下一阶段才讨论 live 接线（需时延与安全
  审计，单独预注册）。

## 预注册修订案 A1：P1 失败后的 P2（规范宽度 = 192），先于跑批

P1（归一宽度 144）结果：east cubic post 黄召回 0.103→**0.629（R1 通过）**，
但 west cubic 0.843→**0.679（R2 失败）**。原因明确：池帧原生宽是 **192**，
归一 144 把 native 自身也从 192 缩到 144（west native 0.889→0.562），
等于用一个比训练域更小的分辨率跑后处理，损害正例。

**P2（修订臂）**：`post_norm_width=192`（= 池帧原生宽、也是训练/缓存域），
其余完全相同；判据 R1/R2/R3 不变（east cubic ≥0.6、west cubic ≥0.84、
raw 不变）。预期：native 无操作（192==192），cubic/lanczos 的后处理回到
训练域尺度，east 恢复、west 不回归。P1 的失败如实记录，不删除。
