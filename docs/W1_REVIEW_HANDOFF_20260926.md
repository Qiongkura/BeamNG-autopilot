## 3. 统一标注规则（先按这套做 14 帧，再决定要不要改）

1. **只标你实际看过并确认的区域**。没看过的区域留未知（255），**不要**把"没标"当成
   "确定没有漆线"——未标注区域不是负例（方案 §6.2）。
2. 类别取值：`background`(0) / `road`(1) / `line`(2) / 未知(255)。漆线包括：
   左/右边缘线、中央线、白线、黄线、实线、虚线。
3. 逐帧在表里填 `verdict`：`confirm`（提议可用）/ `relabel`（我改了）/ `reject`
   （这帧不适合进评价集）/ `unsure`（需要讨论）；`regions` 写你确认过的区域
   （例如 `line_left,line_right,road_edge`）。
4. **不要**把一个目录整体标成 `human_revision`：凭证必须对应"你实际看过的帧"
   （方案 §6.1）。包内帧与工作表一一对应。
5. 遇到"看不清是否有线"的帧，标 `unsure` 并在 `notes` 写原因——这类帧正是
   "退化与遮挡"类要统计的，不是废帧。
