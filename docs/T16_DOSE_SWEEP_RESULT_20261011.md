## 3. 按预注册规则的读数

1. **d100 vs d20：5/5 配对种子为正（mean +0.087）且臂内方差最小**（std 0.049 vs
   0.13–0.15）——完全线帧池在本设置下不仅均值更高，训练**更稳定**。稀释假说
   在正式 5 种子实验中方向复现并加强。
2. **中间剂量无清晰方向**：d33 均值低于 d20（差值 2/5 正向、std 0.251），
   d50 介于其间（4/5 正向）。趋势在均值上大致单调（0.369 → 0.341 → 0.444 →
   0.457）但 d33 的噪声掩盖了方向——正式结论只能说「高剂量（d50+）优于稀释，
   全线池最稳」，不能给出精确阈值。
3. **臂内种子变异是第一噪声源**：d20 出现 s46=0.17 的崩坏种子（试点 ArmA-s43
   val mIoU 0.32 同型）——「会话/种子级变异大于处理效应」在离线训练侧同样成立，
   这本身就是对 R3「两轮候选均拒绝」的机制性解释之一。
4. precision 形态随剂量变化（0.58→0.89）而 recall 持平：剂量改变的是误报行为，
   不是检出能力。

## 4. 边界（预注册既有，未改变）

* 组成与独立帧曝光在因子定义下不可分（15–75 帧同步变化）；
* 单地图池族、单初始化、60 步预算；n=5 为探索性配对，不做显著性声称；
* **不改任何门、不晋级模型**；GPU 分钟照台账记录；不消费封存最终集。

## 5. 对下一轮的操作含义（仅记录，未实施）

* 自动数据的负例目录进入线任务训练池时必须按 `line_evidence` 占比显式配比，
  高稀释配比（≥3:1 无线:有线）应默认隔离为负例专用臂；
* 正式配方冻结前需要：更多线帧池（当前仅 1 个线帧池族）、步预算扫描、
  以及把「候选 vs baseline 的崩坏种子检测」加进回路判据。
