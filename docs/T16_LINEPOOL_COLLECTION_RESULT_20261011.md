# 第二线帧池族采集结果（2026-10-11）：正控制未获得，负例入库存

预注册：[T16_LINEPOOL_COLLECTION_PREREG_20261011.md](T16_LINEPOOL_COLLECTION_PREREG_20261011.md)
（先于采集提交，commit `a5cab37`）。

## 1. 实际执行

* `m5_controlled_scenes.py --map italy --anchors 1 --sites 8 --frames 3
  --step-m 2.0 --anchor-offset 24 --line-convention tiers`：
  8 站 → 采集侧合格 2 / 隔离 3 / N-A 3；产线 25 帧；游戏收尾
  `closed=True`、进程归零。
* `m5_auto_truth_export.py`（冻结门）：**准入 3 池、9 帧，全部无线负例**
  （`known_no_line_a0s1/a0s7`、`structure_negative_a0s5`，均 engine_verified）；
  含线站点（如 `known_line_a0s6`，annotation 线像素 628）**全部隔离**。
  输出：`logs/experiments/t16_linepool_20261011/auto_truth/`。

## 2. 隔离原因（逐条，原样）

含线站点未通过三道独立冻结门的至少一道：

1. **投影标定残差超限**（1.32 px > 1.0，或 2.70/8.51/32.75 px > 2.0）——
   生成侧线几何与标注投影未验证一致；
2. **标注覆盖 < 0.8**（如 straddled 0.022/0.332，near_left/right 0.52–0.67）——
   引擎标注在该站点不携带这些线；
3. **外观一致率 < 0.9**（如 0.171、0.419）——标注把 RGB 里不像漆线的像素
   标成了线（标注流程忽略遮挡物）。

## 3. 预注册判据

「至少一个准入池 line_px > 0」**未满足**：本轮如实记为**未获得线帧正控制**。
3 个准入无线池按预注册入库为负例供给。

## 4. 结构性结论（比单轮失败更重要）

回查 R2 导出报告：**R2 的 auto-truth 轮同样从未准入含线池**（仅 2 池：
1 个声明无线、1 个未证明含线）。即：受控生成 → 独立导出这条链在
**两轮、两个锚点偏移（12/24）**上都未能产出一个通过冻结门的线真值池；
失败理由是结构性的（标定/覆盖/外观三道各自独立拒），不是站点运气。

这与 E4 的结论同类且更强：**新线真值池的供给被「生成线 → 标注验证」链阻断**。
放宽这些门是被禁止的（"A failed attempt never lowers these thresholds"）——
解开它需要代码侧工作：标定/外观验证链与生成器的对齐修正，属于独立批次，
不属于采集轮。

## 5. 对配比实验的影响

* 跨池族配比实验（第二线帧族）在真值链修复前**不可执行**；组成实验继续以
  人工标注池（e2_it3 等）为线帧供给，负例供给从本轮起有 3 个 verified 池可选；
* 剂量扫描的结论（高占比更优更稳）不受影响——它用的是已准入池。
